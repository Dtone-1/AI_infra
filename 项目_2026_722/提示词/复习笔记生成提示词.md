# 复习笔记生成提示词

使用方式：当你在同一个聊天窗口里问完一批基础概念问题后，发送这段提示词，让 GPT 从最近一次【复习整理起点】之后开始整理问答，并生成 Markdown 复习笔记。

---

开始生成复习笔记。

请整理本聊天窗口中从最近一次【复习整理起点】之后，到当前最后一条对话之间的所有“我提出的问题”和“你给出的回答”。

整理目标：把这些概念问答整理成一个适合我复习的 Markdown 文件。不要把原回答完整复制进去，而是要压缩成“复习版答案”，让我复习时能快速抓住重点。

请严格按提问顺序整理，不要打乱顺序。

# 整理要求

## 1. 保留原始问题

每个条目先写出我当时问的问题，尽量保持原问题表达。

格式：

```markdown
## 1. 问题：xxx
```

## 2. 精简回答

每个问题下面给出精简后的复习答案。

要求：

1. 缩短回答，但不能丢失核心含义；
2. 优先解释“是什么、为什么重要、和前后知识的关系”；
3. 删除原回答中的重复解释、过长类比、过多例子；
4. 保留最关键的类比和总结；

格式：

```markdown
### 复习版答案

xxx
```

# 输出文件要求

请生成一个 Markdown 文件，文件名为：

```text
“该聊天窗口的名称”-“当天日期”.md
```

Markdown 文件结构如下：

```markdown
# 基础概念问答复习笔记

## 整理范围说明

说明本文件整理的是从最近一次【复习整理起点】之后到当前对话结束之间的问答内容。

## 问答复习整理

## 1. 问题：xxx

### 复习版答案


```

请使用中文，内容要适合我后续快速复习。不要写成很长的讲义，要写成高密度复习笔记。
