## 二叉树基础结构说明

LeetCode 中大多数二叉树题默认使用如下节点结构：

```python
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
```

含义：

- `val`：当前节点的值。
- `left`：当前节点的左子节点。
- `right`：当前节点的右子节点。
- 如果某个子节点不存在，则为 `None`。

二叉树题最核心的思想是：**把一棵树拆成根节点、左子树、右子树，然后递归或层序处理。**

## 1. #94 二叉树的中序遍历

### 题目描述

给你一棵二叉树的根节点 `root`，返回它的中序遍历结果。

中序遍历顺序是：

```text
左子树 -> 根节点 -> 右子树
```

### 示例

**示例 1：**

```text
输入: root = [1, null, 2, 3]
结构:
   1
    \
     2
    /
   3
输出: [1, 3, 2]
```

**示例 2：**

```text
输入: root = []
输出: []
```

**示例 3：**

```text
输入: root = [1]
输出: [1]
```

### Python 解法一：递归写法

```python
from typing import List, Optional

class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        ans = []

        def dfs(node):
            if not node:
                return
            dfs(node.left)
            ans.append(node.val)
            dfs(node.right)

        dfs(root)
        return ans
```

### 代码详细解析

#### 思路分析

中序遍历就是固定顺序：先处理左子树，再处理当前节点，最后处理右子树。递归天然适合树，因为每个节点都可以看成一棵小树的根。

#### 逐行解析

- `from typing import List, Optional`：导入类型注解工具。
  - `List[int]` 表示返回值是整数列表。
  - `Optional[TreeNode]` 表示 `root` 可能是 `TreeNode`，也可能是 `None`。
- `ans = []`：创建结果数组，用来保存遍历到的节点值。
- `def dfs(node):`：定义递归函数，作用是遍历以 `node` 为根的子树。
- `if not node:`：如果当前节点为空，直接返回。
- `dfs(node.left)`：先递归遍历左子树。
- `ans.append(node.val)`：访问当前节点，把值加入结果数组。
- `dfs(node.right)`：最后递归遍历右子树。
- `dfs(root)`：从整棵树的根节点开始遍历。
- `return ans`：返回最终结果。

#### 关键语法

- `append`：列表方法，用于在数组末尾添加元素。
- `if not node`：判断节点是否为空。
- 递归函数必须有终止条件，否则会无限递归。

### Python 解法二：迭代写法

```python
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        ans = []
        stack = []
        cur = root

        while cur or stack:
            while cur:
                stack.append(cur)
                cur = cur.left

            cur = stack.pop()
            ans.append(cur.val)
            cur = cur.right

        return ans
```

### 迭代写法解析

- `stack`：用栈模拟递归过程。
- `cur = root`：当前节点从根开始。
- `while cur or stack:`：只要当前节点不为空，或者栈里还有节点，就继续。
- 内层 `while cur:`：一直向左走，把路过的节点入栈。
- `cur = stack.pop()`：弹出最左侧还没访问的节点。
- `ans.append(cur.val)`：访问该节点。
- `cur = cur.right`：转向右子树。

中序遍历迭代写法的核心是：**一直向左压栈，弹出后访问，再去右边。**

## 2. #104 二叉树的最大深度

### 题目描述

给你一棵二叉树的根节点 `root`，返回这棵树的最大深度。

最大深度指的是：从根节点到最远叶子节点的最长路径上的节点个数。

### 示例

**示例 1：**

```text
输入: root = [3,9,20,null,null,15,7]
结构:
      3
     / \
    9  20
       / \
      15  7
输出: 3
```

**示例 2：**

```text
输入: root = [1,null,2]
输出: 2
```

### Python 解法

```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0

        left_depth = self.maxDepth(root.left)
        right_depth = self.maxDepth(root.right)

        return max(left_depth, right_depth) + 1
```

### 代码详细解析

#### 思路分析

一棵树的最大深度等于：

```text
max(左子树最大深度, 右子树最大深度) + 1
```

其中 `+1` 表示当前根节点本身占一层。

#### 逐行解析

- `if not root:`：如果树为空，高度就是 0。
- `left_depth = self.maxDepth(root.left)`：递归计算左子树深度。
- `right_depth = self.maxDepth(root.right)`：递归计算右子树深度。
- `max(left_depth, right_depth)`：取左右子树中更深的一边。
- `+ 1`：加上当前节点这一层。
- `return ...`：返回当前这棵子树的最大深度。

#### 关键语法

- `self.maxDepth(...)`：在类的方法里递归调用当前方法。
- `max(a, b)`：返回两个数中的较大值。

#### 复杂度

- 时间复杂度：`O(n)`，每个节点访问一次。
- 空间复杂度：`O(h)`，`h` 是树高，来自递归调用栈。

## 3. #226 翻转二叉树

### 题目描述

给你一棵二叉树的根节点 `root`，请把整棵树左右翻转，并返回翻转后的根节点。

### 示例

**示例 1：**

```text
输入:
      4
    /   \
   2     7
  / \   / \
 1   3 6   9

输出:
      4
    /   \
   7     2
  / \   / \
 9   6 3   1
```

**示例 2：**

```text
输入: [2,1,3]
输出: [2,3,1]
```

### Python 解法

```python
class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root:
            return None

        root.left, root.right = root.right, root.left

        self.invertTree(root.left)
        self.invertTree(root.right)

        return root
```

### 代码详细解析

#### 思路分析

翻转二叉树的本质是：对每一个节点，都交换它的左子树和右子树。

只要对根节点交换一次，再递归处理左右子树，整棵树就会被翻转。

#### 逐行解析

- `if not root:`：空树不用翻转，直接返回 `None`。
- `root.left, root.right = root.right, root.left`：交换当前节点的左右孩子。
- `self.invertTree(root.left)`：递归翻转交换后的左子树。
- `self.invertTree(root.right)`：递归翻转交换后的右子树。
- `return root`：返回翻转后的根节点。

#### 关键语法

- `a, b = b, a`：Python 中常见的交换变量写法。
- 递归的核心是“当前节点做交换，其余交给子树”。

## 4. #101 对称二叉树

### 题目描述

给你一棵二叉树的根节点 `root`，判断它是否是轴对称的。

也就是说，左子树和右子树要像镜子一样对应。

### 示例

**示例 1：**

```text
输入: root = [1,2,2,3,4,4,3]
结构:
        1
      /   \
     2     2
    / \   / \
   3   4 4   3
输出: True
```

**示例 2：**

```text
输入: root = [1,2,2,null,3,null,3]
输出: False
```

### Python 解法

```python
class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        def check(left, right):
            if not left and not right:
                return True
            if not left or not right:
                return False
            if left.val != right.val:
                return False

            return check(left.left, right.right) and check(left.right, right.left)

        return check(root.left, root.right) if root else True
```

### 代码详细解析

#### 思路分析

判断一棵树是否对称，本质上是判断：

- 左子树的左边是否等于右子树的右边；
- 左子树的右边是否等于右子树的左边；
- 当前两个节点的值是否相等。

这是“镜像递归”。

#### 逐行解析

- `def check(left, right):`：定义辅助函数，判断两个子树是否互为镜像。
- `if not left and not right:`：两个节点都为空，说明这一部分对称。
- `if not left or not right:`：一个为空，一个不为空，不对称。
- `if left.val != right.val:`：两个节点值不同，不对称。
- `return check(left.left, right.right) and check(left.right, right.left)`：
  - 左节点的左子树要和右节点的右子树镜像；
  - 左节点的右子树要和右节点的左子树镜像；
  - 两个条件都成立才对称。
- `return check(root.left, root.right) if root else True`：
  - 如果根节点为空，空树也可以认为是对称的。

#### 关键语法

- `and`：逻辑与，两个条件都为真才返回真。
- `A if 条件 else B`：Python 三元表达式。

## 5. #543 二叉树的直径

### 题目描述

给你一棵二叉树的根节点 `root`，返回这棵树的直径。

二叉树的直径指的是：任意两个节点之间最长路径的边数。这条路径不一定经过根节点。

### 示例

**示例 1：**

```text
输入: root = [1,2,3,4,5]
结构:
      1
     / \
    2   3
   / \
  4   5
输出: 3
解释: 最长路径是 4 -> 2 -> 1 -> 3，边数为 3
```

**示例 2：**

```text
输入: root = [1,2]
输出: 1
```

### Python 解法

```python
class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        self.ans = 0

        def depth(node):
            if not node:
                return 0

            left = depth(node.left)
            right = depth(node.right)

            self.ans = max(self.ans, left + right)

            return max(left, right) + 1

        depth(root)
        return self.ans
```

### 代码详细解析

#### 思路分析

对于任意一个节点，如果最长路径经过它，那么路径长度等于：

```text
左子树深度 + 右子树深度
```

所以我们在计算每个节点深度的同时，顺便更新最大直径。

#### 逐行解析

- `self.ans = 0`：保存当前找到的最大直径。
- `def depth(node):`：定义函数，返回以 `node` 为根的最大深度。
- `if not node:`：空节点深度为 0。
- `left = depth(node.left)`：计算左子树深度。
- `right = depth(node.right)`：计算右子树深度。
- `self.ans = max(self.ans, left + right)`：
  - 如果最长路径经过当前节点，那么边数就是 `left + right`。
  - 用它更新全局最大值。
- `return max(left, right) + 1`：返回当前子树深度。
- `depth(root)`：从根节点开始递归。
- `return self.ans`：返回最大直径。

#### 关键点

- 直径是“边数”，不是节点数。
- 深度函数返回的是节点层数，但 `left + right` 刚好是边数。
- 路径不一定经过整棵树的根，所以必须检查每个节点。

## 6. #102 二叉树的层序遍历

### 题目描述

给你一棵二叉树的根节点 `root`，返回它的层序遍历结果。也就是从上到下、从左到右，一层一层地访问节点。

### 示例

**示例 1：**

```text
输入: root = [3,9,20,null,null,15,7]
结构:
      3
     / \
    9  20
       / \
      15  7
输出: [[3], [9, 20], [15, 7]]
```

**示例 2：**

```text
输入: root = [1]
输出: [[1]]
```

**示例 3：**

```text
输入: root = []
输出: []
```

### Python 解法

```python
from collections import deque

class Solution:
    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        if not root:
            return []

        ans = []
        queue = deque([root])

        while queue:
            size = len(queue)
            level = []

            for _ in range(size):
                node = queue.popleft()
                level.append(node.val)

                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)

            ans.append(level)

        return ans
```

### 代码详细解析

#### 思路分析

层序遍历就是广度优先搜索 BFS。

核心工具是队列：
- 先把根节点入队。
- 每次取出队头节点。
- 再把它的左右孩子加入队尾。

为了按层输出，需要在每轮循环开始时记录当前队列长度 `size`，这个长度就是当前层的节点数。

#### 逐行解析

- `from collections import deque`：导入双端队列。
- `if not root:`：空树返回空数组。
- `ans = []`：保存最终结果。
- `queue = deque([root])`：创建队列，并把根节点放进去。
- `while queue:`：只要队列不为空，就继续遍历。
- `size = len(queue)`：当前层有多少个节点。
- `level = []`：保存当前层的节点值。
- `for _ in range(size):`：循环处理当前层所有节点。
- `node = queue.popleft()`：从队头弹出一个节点。
- `level.append(node.val)`：把当前节点值加入当前层结果。
- `if node.left:`：如果左孩子存在，加入队列。
- `if node.right:`：如果右孩子存在，加入队列。
- `ans.append(level)`：当前层处理完后，加入总结果。
- `return ans`：返回层序遍历结果。

#### 关键语法

- `deque`：比普通列表更适合做队列。
- `popleft()`：从左侧弹出元素，时间复杂度 `O(1)`。
- `range(size)`：保证每一轮只处理当前层，不会混入下一层。

## 7. #108 将有序数组转换为二叉搜索树

### 题目描述

给你一个按升序排列的整数数组 `nums`，请将它转换为一棵高度平衡的二叉搜索树。

高度平衡指的是：每个节点的左右两个子树高度差不超过 1。

### 示例

**示例 1：**

```text
输入: nums = [-10, -3, 0, 5, 9]
一种可能输出: [0, -3, 9, -10, null, 5]
解释: 选择中间元素 0 作为根节点，左右两边分别构造左右子树
```

**示例 2：**

```text
输入: nums = [1, 3]
一种可能输出: [3, 1]
或者: [1, null, 3]
```

### Python 解法

```python
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        def build(left, right):
            if left > right:
                return None

            mid = (left + right) // 2
            root = TreeNode(nums[mid])

            root.left = build(left, mid - 1)
            root.right = build(mid + 1, right)

            return root

        return build(0, len(nums) - 1)
```

### 代码详细解析

#### 思路分析

有序数组要构造平衡二叉搜索树，最自然的做法是：

- 选择中间元素作为根节点；
- 左半部分构造左子树；
- 右半部分构造右子树。

这样左右子树的节点数量接近，树就比较平衡。

#### 逐行解析

- `def build(left, right):`：递归函数，负责把 `nums[left:right+1]` 构造成 BST。
- `if left > right:`：区间为空，返回 `None`。
- `mid = (left + right) // 2`：取中间下标。
- `root = TreeNode(nums[mid])`：用中间元素创建根节点。
- `root.left = build(left, mid - 1)`：左半区间构造左子树。
- `root.right = build(mid + 1, right)`：右半区间构造右子树。
- `return root`：返回当前子树根节点。
- `return build(0, len(nums) - 1)`：从整个数组范围开始构造。

#### 关键语法

- `//`：整除，得到整数下标。
- 递归构造树时，常用“返回子树根节点”的方式。

## 8. #98 验证二叉搜索树

### 题目描述

给你一棵二叉树的根节点 `root`，判断它是否是有效的二叉搜索树。

二叉搜索树需要满足：

- 节点的左子树中所有节点值都小于当前节点值；
- 节点的右子树中所有节点值都大于当前节点值；
- 左右子树本身也必须是二叉搜索树。

### 示例

**示例 1：**

```text
输入: root = [2,1,3]
输出: True
```

**示例 2：**

```text
输入: root = [5,1,4,null,null,3,6]
输出: False
解释: 根节点为 5，但右子树中有节点 3，小于 5
```

### Python 解法一：上下界递归

```python
class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        def check(node, low, high):
            if not node:
                return True

            if not (low < node.val < high):
                return False

            return check(node.left, low, node.val) and check(node.right, node.val, high)

        return check(root, float('-inf'), float('inf'))
```

### 代码详细解析

#### 思路分析

只判断 `root.left.val < root.val < root.right.val` 是不够的，因为 BST 的限制是“整棵子树范围”，不是只看直接孩子。

所以我们给每个节点设置一个合法范围：

```text
low < node.val < high
```

- 去左子树时，上界变成当前节点值。
- 去右子树时，下界变成当前节点值。

#### 逐行解析

- `def check(node, low, high):`：判断以 `node` 为根的子树是否满足值域范围。
- `if not node:`：空树是合法 BST。
- `if not (low < node.val < high):`：当前节点值必须严格在上下界之间。
- `return False`：不满足范围，直接失败。
- `check(node.left, low, node.val)`：左子树所有节点必须小于当前节点。
- `check(node.right, node.val, high)`：右子树所有节点必须大于当前节点。
- `float('-inf')`：负无穷。
- `float('inf')`：正无穷。

#### 关键语法

- `low < node.val < high`：Python 支持连续比较。
- `float('inf')`：表示无穷大。

### Python 解法二：中序遍历

```python
class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        self.prev = float('-inf')

        def inorder(node):
            if not node:
                return True

            if not inorder(node.left):
                return False

            if node.val <= self.prev:
                return False
            self.prev = node.val

            return inorder(node.right)

        return inorder(root)
```

### 中序写法解析

二叉搜索树的中序遍历结果一定是严格递增的。因此只要在中序遍历过程中发现当前值小于等于前一个值，就不是合法 BST。

## 9. #230 二叉搜索树中第 K 小的元素

### 题目描述

给你一棵二叉搜索树的根节点 `root` 和一个整数 `k`，请你返回树中第 `k` 小的节点值。

### 示例

**示例 1：**

```text
输入: root = [3,1,4,null,2], k = 1
结构:
    3
   / \
  1   4
   \
    2
输出: 1
```

**示例 2：**

```text
输入: root = [5,3,6,2,4,null,null,1], k = 3
输出: 3
```

### Python 解法

```python
class Solution:
    def kthSmallest(self, root: Optional[TreeNode], k: int) -> int:
        stack = []
        cur = root

        while cur or stack:
            while cur:
                stack.append(cur)
                cur = cur.left

            cur = stack.pop()
            k -= 1
            if k == 0:
                return cur.val

            cur = cur.right
```

### 代码详细解析

#### 思路分析

二叉搜索树的中序遍历结果是升序排列的。

所以第 `k` 小的元素，就是中序遍历过程中第 `k` 个访问到的节点。

#### 逐行解析

- `stack = []`：用栈模拟中序遍历。
- `cur = root`：当前指针从根节点开始。
- `while cur or stack:`：只要还有节点没处理，就继续。
- `while cur:`：一路向左，把节点压栈。
- `stack.append(cur)`：保存当前节点，等待后续访问。
- `cur = cur.left`：继续往左走。
- `cur = stack.pop()`：弹出当前最小的未访问节点。
- `k -= 1`：访问了一个节点，计数减一。
- `if k == 0:`：说明当前节点就是第 `k` 小。
- `return cur.val`：返回答案。
- `cur = cur.right`：访问完当前节点后，转向右子树。

#### 关键点

- BST + 第 k 小，优先想到中序遍历。
- 迭代写法可以在找到答案时提前返回，不必遍历完整棵树。

## 10. #199 二叉树的右视图

### 题目描述

给你一棵二叉树的根节点 `root`，想象你站在这棵树的右侧，返回从上到下能看到的节点值。

### 示例

**示例 1：**

```text
输入: root = [1,2,3,null,5,null,4]
结构:
      1
     / \
    2   3
     \   \
      5   4
输出: [1, 3, 4]
```

**示例 2：**

```text
输入: root = [1,null,3]
输出: [1, 3]
```

**示例 3：**

```text
输入: root = []
输出: []
```

### Python 解法：层序遍历

```python
from collections import deque

class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []

        ans = []
        queue = deque([root])

        while queue:
            size = len(queue)

            for i in range(size):
                node = queue.popleft()

                if i == size - 1:
                    ans.append(node.val)

                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)

        return ans
```

### 代码详细解析

#### 思路分析

右视图就是每一层最右边的节点。

层序遍历时，我们按从左到右的顺序处理每层节点，那么每层的最后一个节点就是右视图节点。

#### 逐行解析

- `if not root:`：空树没有右视图。
- `ans = []`：保存右视图结果。
- `queue = deque([root])`：队列初始化为根节点。
- `size = len(queue)`：当前层节点数。
- `for i in range(size):`：遍历当前层。
- `node = queue.popleft()`：取出当前节点。
- `if i == size - 1:`：如果是当前层最后一个节点，就加入结果。
- `if node.left:`、`if node.right:`：把下一层节点加入队列。
- `return ans`：返回结果。

#### 关键语法

- `i == size - 1`：判断当前节点是不是这一层最后一个。
- BFS 按层处理时，`size` 非常关键。

## 11. #114 二叉树展开为链表

### 题目描述

给你一棵二叉树的根节点 `root`，请你原地将它展开为一个单链表。

展开后的链表应该满足：

- 使用树节点的 `right` 指针表示链表的下一个节点；
- 所有 `left` 指针都应该为 `None`；
- 节点顺序应该与二叉树的前序遍历顺序一致。

### 示例

**示例 1：**

```text
输入:
      1
     / \
    2   5
   / \   \
  3   4   6

输出:
1 -> 2 -> 3 -> 4 -> 5 -> 6
```

**示例 2：**

```text
输入: root = []
输出: []
```

**示例 3：**

```text
输入: root = [0]
输出: [0]
```

### Python 解法

```python
class Solution:
    def flatten(self, root: Optional[TreeNode]) -> None:
        cur = root

        while cur:
            if cur.left:
                predecessor = cur.left
                while predecessor.right:
                    predecessor = predecessor.right

                predecessor.right = cur.right
                cur.right = cur.left
                cur.left = None

            cur = cur.right
```

### 代码详细解析

#### 思路分析

前序遍历顺序是：

```text
根 -> 左 -> 右
```

展开链表时，当前节点的右边应该接原来的左子树，然后左子树最后面的节点再接原来的右子树。

对每个有左子树的节点：

1. 找到左子树中最右边的节点 `predecessor`。
2. 把当前节点原来的右子树接到 `predecessor.right`。
3. 把当前节点的左子树整体挪到右边。
4. 把当前节点的左指针置空。

#### 逐行解析

- `cur = root`：从根节点开始处理。
- `while cur:`：只要当前节点存在，就继续。
- `if cur.left:`：只有当前节点有左子树时，才需要调整。
- `predecessor = cur.left`：从左子树根节点开始找最右节点。
- `while predecessor.right:`：一直往右走，直到找到左子树中最右边的节点。
- `predecessor.right = cur.right`：把原来的右子树接到左子树最右节点后面。
- `cur.right = cur.left`：把左子树移动到右边。
- `cur.left = None`：左指针置空，符合题目要求。
- `cur = cur.right`：沿着展开后的右链继续处理。

#### 关键点

- 这道题要求原地修改，不是返回新链表。
- `flatten` 的返回值是 `None`，LeetCode 会检查原树是否被正确修改。

## 12. #105 从前序与中序遍历序列构造二叉树

### 题目描述

给你两个整数数组 `preorder` 和 `inorder`，分别表示一棵二叉树的前序遍历和中序遍历。请你根据这两个数组构造并返回这棵二叉树。

前序遍历顺序：

```text
根 -> 左 -> 右
```

中序遍历顺序：

```text
左 -> 根 -> 右
```

### 示例

**示例 1：**

```text
输入:
preorder = [3, 9, 20, 15, 7]
inorder  = [9, 3, 15, 20, 7]
输出: [3, 9, 20, null, null, 15, 7]
```

**示例 2：**

```text
输入:
preorder = [-1]
inorder  = [-1]
输出: [-1]
```

### Python 解法

```python
class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        index = {value: i for i, value in enumerate(inorder)}
        self.pre_idx = 0

        def build(left, right):
            if left > right:
                return None

            root_val = preorder[self.pre_idx]
            self.pre_idx += 1

            root = TreeNode(root_val)
            mid = index[root_val]

            root.left = build(left, mid - 1)
            root.right = build(mid + 1, right)

            return root

        return build(0, len(inorder) - 1)
```

### 代码详细解析

#### 思路分析

前序数组的第一个元素一定是当前子树的根节点。

在中序数组中找到这个根节点，就可以把中序数组分成两部分：

- 左边是左子树；
- 右边是右子树。

然后递归构造左右子树。

#### 逐行解析

- `index = {value: i for i, value in enumerate(inorder)}`：
  - 建立值到下标的映射。
  - 这样可以快速在中序数组中找到根节点位置。
- `self.pre_idx = 0`：记录当前用到了前序数组的哪个位置。
- `def build(left, right):`：构造中序区间 `[left, right]` 对应的子树。
- `if left > right:`：区间为空，返回 `None`。
- `root_val = preorder[self.pre_idx]`：当前前序位置就是根节点值。
- `self.pre_idx += 1`：用完一个根节点后，前序指针后移。
- `root = TreeNode(root_val)`：创建根节点。
- `mid = index[root_val]`：找到根节点在中序数组中的位置。
- `root.left = build(left, mid - 1)`：递归构造左子树。
- `root.right = build(mid + 1, right)`：递归构造右子树。
- `return root`：返回当前子树根节点。

#### 关键语法

- `enumerate(inorder)`：遍历数组时同时得到下标和值。
- 字典推导式 `{value: i for i, value in enumerate(inorder)}`：快速创建哈希表。

## 13. #437 路径总和 III

### 题目描述

给你一棵二叉树的根节点 `root` 和一个整数 `targetSum`，请你统计路径和等于 `targetSum` 的路径数量。

路径要求：

- 必须从某个节点向下走；
- 可以从任意节点开始；
- 可以在任意节点结束；
- 不一定从根节点开始，也不一定到叶子节点结束。

### 示例

**示例 1：**

```text
输入: root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8
输出: 3
解释: 满足条件的路径有：
5 -> 3
5 -> 2 -> 1
-3 -> 11
```

**示例 2：**

```text
输入: root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22
输出: 3
```

### Python 解法：前缀和 + 哈希表

```python
from collections import defaultdict

class Solution:
    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> int:
        prefix_count = defaultdict(int)
        prefix_count[0] = 1
        self.ans = 0

        def dfs(node, current_sum):
            if not node:
                return

            current_sum += node.val
            self.ans += prefix_count[current_sum - targetSum]

            prefix_count[current_sum] += 1

            dfs(node.left, current_sum)
            dfs(node.right, current_sum)

            prefix_count[current_sum] -= 1

        dfs(root, 0)
        return self.ans
```

### 代码详细解析

#### 思路分析

这道题可以类比“和为 K 的子数组”。

从根到当前节点的路径和叫 `current_sum`。如果之前某个祖先节点处的前缀和是 `old_sum`，并且：

```text
current_sum - old_sum = targetSum
```

那么从那个祖先的下一个节点到当前节点的路径和就是 `targetSum`。

所以要找：

```text
old_sum = current_sum - targetSum
```

用哈希表记录当前路径上出现过的前缀和次数。

#### 逐行解析

- `from collections import defaultdict`：导入带默认值的字典。
- `prefix_count = defaultdict(int)`：创建哈希表，默认值为 0。
- `prefix_count[0] = 1`：初始化前缀和 0 出现一次，表示从根节点开始的路径也能被统计。
- `self.ans = 0`：记录满足条件的路径数量。
- `def dfs(node, current_sum):`：递归遍历树，并传入当前路径和。
- `if not node:`：空节点直接返回。
- `current_sum += node.val`：更新从根到当前节点的路径和。
- `self.ans += prefix_count[current_sum - targetSum]`：
  - 查找是否存在某个之前的前缀和，使得中间路径和等于目标值。
  - 有几次，就说明有几条路径。
- `prefix_count[current_sum] += 1`：当前前缀和加入哈希表。
- `dfs(node.left, current_sum)`：递归左子树。
- `dfs(node.right, current_sum)`：递归右子树。
- `prefix_count[current_sum] -= 1`：回溯，离开当前节点时撤销当前前缀和。

#### 关键点

- 必须回溯，否则左子树的前缀和会错误影响右子树。
- `prefix_count` 只记录“当前递归路径”上的前缀和，不是整棵树所有节点的前缀和。

#### 关键语法

- `defaultdict(int)`：访问不存在的键时自动返回 0。
- `+=` 和 `-=`：自增、自减写法。

## 14. #236 二叉树的最近公共祖先

### 题目描述

给你一棵二叉树的根节点 `root`，以及树中的两个节点 `p` 和 `q`，请返回它们的最近公共祖先。

最近公共祖先指的是：同时拥有 `p` 和 `q` 作为后代的最深节点。一个节点也可以是它自己的后代。

### 示例

**示例 1：**

```text
输入: root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出: 3
解释: 5 和 1 的最近公共祖先是 3
```

**示例 2：**

```text
输入: root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
输出: 5
解释: 5 是 4 的祖先，所以最近公共祖先是 5
```

### Python 解法

```python
class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        if not root or root == p or root == q:
            return root

        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)

        if left and right:
            return root

        return left if left else right
```

### 代码详细解析

#### 思路分析

递归函数的含义：在以 `root` 为根的子树中寻找 `p` 或 `q`，如果找到了就返回对应节点；如果左右子树分别找到一个，说明当前 `root` 就是最近公共祖先。

#### 逐行解析

- `if not root or root == p or root == q:`：
  - 如果当前节点为空，返回 `None`。
  - 如果当前节点就是 `p` 或 `q`，返回当前节点。
- `left = self.lowestCommonAncestor(root.left, p, q)`：去左子树寻找。
- `right = self.lowestCommonAncestor(root.right, p, q)`：去右子树寻找。
- `if left and right:`：
  - 左子树找到了一个，右子树也找到了一个；
  - 说明 `p` 和 `q` 分布在当前节点两侧；
  - 当前节点就是最近公共祖先。
- `return root`：返回当前节点。
- `return left if left else right`：
  - 如果只有左边找到了，就返回左边结果；
  - 如果只有右边找到了，就返回右边结果；
  - 如果都没有找到，返回 `None`。

#### 关键点

- 这道题不需要父指针。
- 普通二叉树的最近公共祖先不能用 BST 的大小关系，只能递归搜索。

## 15. #124 二叉树中的最大路径和

### 题目描述

给你一棵非空二叉树的根节点 `root`，返回树中的最大路径和。

路径定义为：从树中任意一个节点出发，沿父子连接到任意一个节点，路径中每个节点最多出现一次。路径不一定经过根节点。

### 示例

**示例 1：**

```text
输入: root = [1,2,3]
结构:
    1
   / \
  2   3
输出: 6
解释: 最大路径是 2 -> 1 -> 3，路径和为 6
```

**示例 2：**

```text
输入: root = [-10,9,20,null,null,15,7]
结构:
       -10
       / \
      9  20
        /  \
       15   7
输出: 42
解释: 最大路径是 15 -> 20 -> 7，路径和为 42
```

### Python 解法

```python
class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        self.ans = float('-inf')

        def gain(node):
            if not node:
                return 0

            left_gain = max(gain(node.left), 0)
            right_gain = max(gain(node.right), 0)

            current_path = node.val + left_gain + right_gain
            self.ans = max(self.ans, current_path)

            return node.val + max(left_gain, right_gain)

        gain(root)
        return self.ans
```

### 代码详细解析

#### 思路分析

这道题和 #543 二叉树直径很像，但是路径长度换成了路径和，并且节点值可能是负数。

对每个节点，有两种角色：

1. **作为路径最高点**：路径可以从左子树经过当前节点到右子树。
   - 路径和：`node.val + left_gain + right_gain`
   - 用来更新全局答案。

2. **作为向父节点提供的单边贡献**：只能选择左边或右边其中一条路继续往上。
   - 返回值：`node.val + max(left_gain, right_gain)`

为什么不能把左右两边都返回给父节点？

因为路径不能分叉。如果当前节点已经同时接了左边和右边，再往父节点走就会变成三叉路径，不符合题意。

#### 逐行解析

- `self.ans = float('-inf')`：最大路径和初始化为负无穷，因为节点值可能全是负数。
- `def gain(node):`：定义函数，计算当前节点能向父节点贡献的最大单边路径和。
- `if not node:`：空节点贡献 0。
- `left_gain = max(gain(node.left), 0)`：
  - 计算左子树贡献。
  - 如果贡献为负，不如不要，所以和 0 取最大值。
- `right_gain = max(gain(node.right), 0)`：同理处理右子树贡献。
- `current_path = node.val + left_gain + right_gain`：
  - 以当前节点作为路径最高点时的路径和。
- `self.ans = max(self.ans, current_path)`：更新全局最大路径和。
- `return node.val + max(left_gain, right_gain)`：
  - 返回给父节点时，只能选择左边或右边其中一条更大的路径。
- `gain(root)`：从根节点开始递归。
- `return self.ans`：返回最终答案。

#### 关键点

- `self.ans` 是全局最大路径和。
- `gain(node)` 返回的是“单边最大贡献”，不是完整最大路径。
- 负数路径会拖累结果，所以用 `max(..., 0)` 舍弃负贡献。

# 二叉树题型总结

## 1. 深度优先搜索 DFS

典型题目：

- #94 二叉树的中序遍历
- #104 二叉树的最大深度
- #226 翻转二叉树
- #101 对称二叉树
- #543 二叉树的直径
- #98 验证二叉搜索树
- #236 二叉树的最近公共祖先
- #124 二叉树中的最大路径和

核心思想：

```text
处理当前节点 -> 递归处理左子树 -> 递归处理右子树
```

或者：

```text
先从左右子树拿结果 -> 再计算当前节点答案
```

## 2. 广度优先搜索 BFS

典型题目：

- #102 二叉树的层序遍历
- #199 二叉树的右视图

核心工具：

```python
from collections import deque
```

核心写法：

```python
while queue:
    size = len(queue)
    for _ in range(size):
        node = queue.popleft()
```

`size` 用来区分当前层和下一层。

## 3. 二叉搜索树 BST

典型题目：

- #108 将有序数组转换为二叉搜索树
- #98 验证二叉搜索树
- #230 二叉搜索树中第 K 小的元素

重要性质：

```text
BST 的中序遍历结果是严格递增序列
```

看到 BST，一定优先考虑中序遍历。

## 4. 构造二叉树

典型题目：

- #108 将有序数组转换为二叉搜索树
- #105 从前序与中序遍历序列构造二叉树

核心思想：

- 找到根节点；
- 确定左子树范围；
- 确定右子树范围；
- 递归构造。

## 5. 树形动态规划

典型题目：

- #543 二叉树的直径
- #124 二叉树中的最大路径和
- #437 路径总和 III

树形 DP 的关键是分清楚：

```text
递归函数返回给父节点的值是什么？
当前节点用来更新全局答案的值是什么？
```

例如 #124：

- 返回值是“单边最大贡献”；
- 更新答案时可以同时使用左边和右边。
