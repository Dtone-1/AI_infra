## 1. #35 搜索插入位置

### 题目描述

给你一个升序排列、没有重复元素的整数数组 `nums`，以及一个目标值 `target`。

请你在数组中搜索 `target`：

- 如果 `target` 存在，返回它的下标；
- 如果 `target` 不存在，返回它应该被插入的位置，使数组仍然保持升序。

要求算法时间复杂度为 `O(log n)`。

### 示例

**示例 1：**

```text
输入: nums = [1,3,5,6], target = 5
输出: 2
解释: 5 在数组中的下标是 2。
```

**示例 2：**

```text
输入: nums = [1,3,5,6], target = 2
输出: 1
解释: 2 应该插入到 1 和 3 之间，下标为 1。
```

**示例 3：**

```text
输入: nums = [1,3,5,6], target = 7
输出: 4
解释: 7 比所有元素都大，应该插入到数组末尾。
```

### Python 解法

```python
from typing import List

class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        left = 0
        right = len(nums)

        while left < right:
            mid = (left + right) // 2

            if nums[mid] < target:
                left = mid + 1
            else:
                right = mid

        return left
```

### 代码详细解析

#### 核心思路

这道题要找的是：**第一个大于等于 `target` 的位置**。

例如：

```text
nums = [1,3,5,6], target = 2
```

第一个大于等于 `2` 的元素是 `3`，它的下标是 `1`，所以答案是 `1`。

如果数组中存在 `target`，这个位置就是 `target` 的下标；如果不存在，这个位置就是它应该插入的位置。

#### 为什么用左闭右开区间

代码使用区间：

```text
[left, right)
```

含义是：

- `left` 可以取到；
- `right` 取不到。

初始化：

```python
left = 0
right = len(nums)
```

这样可以自然处理“插入到数组末尾”的情况。  
如果 `target` 比所有元素都大，最终 `left` 会变成 `len(nums)`。

#### 逐行解析

```python
left = 0
right = len(nums)
```

定义二分查找的左右边界。  
这里 `right = len(nums)`，不是 `len(nums) - 1`，说明使用的是左闭右开区间。

```python
while left < right:
```

只要搜索区间不为空，就继续查找。  
当 `left == right` 时，区间为空，搜索结束。

```python
mid = (left + right) // 2
```

取中间位置。  
`//` 是 Python 的整除运算，结果一定是整数。

```python
if nums[mid] < target:
    left = mid + 1
```

如果 `nums[mid]` 小于 `target`，说明答案不可能在 `mid` 以及 `mid` 左边，因为这些位置都太小。  
所以左边界移动到 `mid + 1`。

```python
else:
    right = mid
```

如果 `nums[mid] >= target`，说明 `mid` 有可能就是答案。  
所以不能跳过 `mid`，把右边界收缩到 `mid`。

```python
return left
```

循环结束时，`left` 就是第一个大于等于 `target` 的位置。

#### 关键语法

- `List[int]`：类型注解，表示整数列表。
- `len(nums)`：获取列表长度。
- `//`：整除，例如 `5 // 2 == 2`。
- `while left < right`：二分查找常见循环条件。

#### 复杂度分析

- 时间复杂度：`O(log n)`。
- 空间复杂度：`O(1)`。

## 2. #74 搜索二维矩阵

### 题目描述

给你一个 `m x n` 的整数矩阵 `matrix`，矩阵满足：

1. 每一行中的整数从左到右升序排列；
2. 每一行的第一个整数大于前一行的最后一个整数。

给你一个目标值 `target`，请判断它是否存在于矩阵中。

要求时间复杂度为 `O(log(mn))`。

### 示例

**示例 1：**

```text
输入:
matrix = [
  [1,3,5,7],
  [10,11,16,20],
  [23,30,34,60]
]
target = 3

输出: True
```

**示例 2：**

```text
输入:
matrix = [
  [1,3,5,7],
  [10,11,16,20],
  [23,30,34,60]
]
target = 13

输出: False
```

### Python 解法

```python
from typing import List

class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        rows = len(matrix)
        cols = len(matrix[0])

        left = 0
        right = rows * cols - 1

        while left <= right:
            mid = (left + right) // 2
            r = mid // cols
            c = mid % cols

            if matrix[r][c] == target:
                return True
            elif matrix[r][c] < target:
                left = mid + 1
            else:
                right = mid - 1

        return False
```

### 代码详细解析

#### 核心思路

虽然题目给的是二维矩阵，但由于它满足：

```text
每一行升序
下一行第一个数 > 上一行最后一个数
```

所以可以把它看成一个整体升序的一维数组。

例如矩阵：

```text
[
  [1,3,5,7],
  [10,11,16,20],
  [23,30,34,60]
]
```

可以看成：

```text
[1,3,5,7,10,11,16,20,23,30,34,60]
```

然后对这个“虚拟一维数组”做二分查找。

#### 二维坐标和一维下标的转换

假设列数为 `cols`，一维下标为 `mid`：

```python
r = mid // cols
c = mid % cols
```

例如 `cols = 4`：

```text
mid = 6
r = 6 // 4 = 1
c = 6 % 4 = 2
```

所以一维下标 `6` 对应二维坐标 `(1, 2)`。

#### 逐行解析

```python
rows = len(matrix)
cols = len(matrix[0])
```

获取矩阵的行数和列数。

```python
left = 0
right = rows * cols - 1
```

把矩阵看成长度为 `rows * cols` 的一维数组。  
最后一个元素的一维下标是 `rows * cols - 1`。

```python
while left <= right:
```

使用闭区间 `[left, right]` 进行二分查找。

```python
mid = (left + right) // 2
```

计算中间下标。

```python
r = mid // cols
c = mid % cols
```

把一维下标转换成二维坐标。

```python
if matrix[r][c] == target:
    return True
```

如果找到目标值，直接返回 `True`。

```python
elif matrix[r][c] < target:
    left = mid + 1
```

如果当前值小于目标值，去右半部分找。

```python
else:
    right = mid - 1
```

如果当前值大于目标值，去左半部分找。

```python
return False
```

循环结束仍然没找到，返回 `False`。

#### 关键语法

- `matrix[r][c]`：访问二维矩阵中第 `r` 行第 `c` 列。
- `//`：计算行号。
- `%`：计算列号。
- `rows * cols`：矩阵元素总数。

#### 复杂度分析

- 时间复杂度：`O(log(mn))`。
- 空间复杂度：`O(1)`。

## 3. #34 在排序数组中查找元素的第一个和最后一个位置

### 题目描述

给你一个按非递减顺序排列的整数数组 `nums`，以及一个目标值 `target`。

请你找出 `target` 在数组中的开始位置和结束位置。

如果数组中不存在 `target`，返回 `[-1, -1]`。

要求算法时间复杂度为 `O(log n)`。

### 示例

**示例 1：**

```text
输入: nums = [5,7,7,8,8,10], target = 8
输出: [3,4]
解释: 8 第一次出现的位置是 3，最后一次出现的位置是 4。
```

**示例 2：**

```text
输入: nums = [5,7,7,8,8,10], target = 6
输出: [-1,-1]
解释: 6 不存在。
```

**示例 3：**

```text
输入: nums = [], target = 0
输出: [-1,-1]
```

### Python 解法

```python
from typing import List

class Solution:
    def searchRange(self, nums: List[int], target: int) -> List[int]:
        def lower_bound(x):
            left = 0
            right = len(nums)

            while left < right:
                mid = (left + right) // 2

                if nums[mid] < x:
                    left = mid + 1
                else:
                    right = mid

            return left

        left_index = lower_bound(target)
        right_index = lower_bound(target + 1) - 1

        if left_index == len(nums) or nums[left_index] != target:
            return [-1, -1]

        return [left_index, right_index]
```

### 代码详细解析

#### 核心思路

这道题要找目标值的左右边界。

可以使用两次二分：

1. 找第一个大于等于 `target` 的位置；
2. 找第一个大于等于 `target + 1` 的位置，再减 1，就是 `target` 最后一次出现的位置。

这种写法适用于整数数组。

例如：

```text
nums = [5,7,7,8,8,10], target = 8
```

- `lower_bound(8)` 返回 `3`；
- `lower_bound(9)` 返回 `5`；
- 所以右边界是 `5 - 1 = 4`。

#### lower_bound 的含义

```python
lower_bound(x)
```

返回数组中第一个大于等于 `x` 的位置。

这是二分查找中非常重要的模板。

#### 逐行解析

```python
def lower_bound(x):
```

定义一个内部函数，用来找第一个大于等于 `x` 的位置。

```python
left = 0
right = len(nums)
```

使用左闭右开区间 `[left, right)`。

```python
while left < right:
```

当区间不为空时继续查找。

```python
mid = (left + right) // 2
```

计算中点。

```python
if nums[mid] < x:
    left = mid + 1
```

如果中点值小于 `x`，说明答案在右边。

```python
else:
    right = mid
```

如果中点值大于等于 `x`，说明 `mid` 可能是答案，右边界移动到 `mid`。

```python
return left
```

最终 `left` 就是第一个大于等于 `x` 的位置。

```python
left_index = lower_bound(target)
right_index = lower_bound(target + 1) - 1
```

分别计算左边界和右边界。

```python
if left_index == len(nums) or nums[left_index] != target:
    return [-1, -1]
```

判断目标值是否存在：

- 如果 `left_index == len(nums)`，说明所有元素都小于 `target`；
- 如果 `nums[left_index] != target`，说明第一个大于等于 `target` 的数不是 `target`。

```python
return [left_index, right_index]
```

返回左右边界。

#### 关键语法

- 内部函数：函数里可以再定义函数。
- `target + 1`：因为本题是整数数组，所以可以用第一个大于等于 `target + 1` 的位置确定右边界。
- `left_index == len(nums)`：注意先判断越界，再访问 `nums[left_index]`。

#### 复杂度分析

- 时间复杂度：`O(log n)`，执行两次二分。
- 空间复杂度：`O(1)`。

## 4. #33 搜索旋转排序数组

### 题目描述

整数数组 `nums` 原本是升序排列的，但在某个未知位置进行了旋转。

例如：

```text
原数组: [0,1,2,4,5,6,7]
旋转后: [4,5,6,7,0,1,2]
```

给你旋转后的数组 `nums` 和目标值 `target`，请你返回 `target` 的下标。如果不存在，返回 `-1`。

要求时间复杂度为 `O(log n)`。

### 示例

**示例 1：**

```text
输入: nums = [4,5,6,7,0,1,2], target = 0
输出: 4
```

**示例 2：**

```text
输入: nums = [4,5,6,7,0,1,2], target = 3
输出: -1
```

**示例 3：**

```text
输入: nums = [1], target = 0
输出: -1
```

### Python 解法

```python
from typing import List

class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left = 0
        right = len(nums) - 1

        while left <= right:
            mid = (left + right) // 2

            if nums[mid] == target:
                return mid

            if nums[left] <= nums[mid]:
                if nums[left] <= target < nums[mid]:
                    right = mid - 1
                else:
                    left = mid + 1
            else:
                if nums[mid] < target <= nums[right]:
                    left = mid + 1
                else:
                    right = mid - 1

        return -1
```

### 代码详细解析

#### 核心思路

旋转排序数组虽然整体不是完全有序，但每次二分时，左右两半中一定至少有一半是有序的。

例如：

```text
[4,5,6,7,0,1,2]
```

如果 `mid` 在 `7`：

- 左半 `[4,5,6,7]` 是有序的；
- 右半 `[0,1,2]` 也是有序片段，但断点在中间。

核心判断：

```python
if nums[left] <= nums[mid]:
```

说明左半部分有序。

否则右半部分有序。

然后判断 `target` 是否落在有序的那一半里，如果落在里面，就去那一半找；否则去另一半找。

#### 逐行解析

```python
left = 0
right = len(nums) - 1
```

定义闭区间 `[left, right]`。

```python
while left <= right:
```

只要区间有效，就继续二分。

```python
mid = (left + right) // 2
```

计算中点。

```python
if nums[mid] == target:
    return mid
```

如果中点正好是目标值，直接返回。

```python
if nums[left] <= nums[mid]:
```

判断左半部分是否有序。  
如果 `nums[left] <= nums[mid]`，说明从 `left` 到 `mid` 是升序的。

```python
if nums[left] <= target < nums[mid]:
    right = mid - 1
else:
    left = mid + 1
```

如果目标值落在左半有序区间内，就去左边找；否则去右边找。

```python
else:
```

如果左半不是有序的，那右半一定是有序的。

```python
if nums[mid] < target <= nums[right]:
    left = mid + 1
else:
    right = mid - 1
```

如果目标值落在右半有序区间内，就去右边找；否则去左边找。

```python
return -1
```

循环结束仍没找到，返回 `-1`。

#### 关键语法

- `nums[left] <= target < nums[mid]`：Python 支持连续比较。
- 旋转数组二分的关键不是直接比较 `target` 和 `nums[mid]`，而是先判断哪一半有序。

#### 复杂度分析

- 时间复杂度：`O(log n)`。
- 空间复杂度：`O(1)`。

## 5. #153 寻找旋转排序数组中的最小值

### 题目描述

给你一个经过旋转的升序数组 `nums`，数组中的元素互不相同。

请你找出数组中的最小元素。

要求时间复杂度为 `O(log n)`。

### 示例

**示例 1：**

```text
输入: nums = [3,4,5,1,2]
输出: 1
```

**示例 2：**

```text
输入: nums = [4,5,6,7,0,1,2]
输出: 0
```

**示例 3：**

```text
输入: nums = [11,13,15,17]
输出: 11
解释: 数组没有明显旋转，最小值就是第一个元素。
```

### Python 解法

```python
from typing import List

class Solution:
    def findMin(self, nums: List[int]) -> int:
        left = 0
        right = len(nums) - 1

        while left < right:
            mid = (left + right) // 2

            if nums[mid] > nums[right]:
                left = mid + 1
            else:
                right = mid

        return nums[left]
```

### 代码详细解析

#### 核心思路

旋转排序数组的最小值就是“断点”位置。

例如：

```text
[4,5,6,7,0,1,2]
```

最小值 `0` 是旋转断点。

判断关键是比较 `nums[mid]` 和 `nums[right]`：

1. 如果 `nums[mid] > nums[right]`  
   说明最小值一定在 `mid` 右边。

2. 如果 `nums[mid] <= nums[right]`  
   说明从 `mid` 到 `right` 是有序的，最小值可能就是 `mid`，也可能在左边。

#### 逐行解析

```python
left = 0
right = len(nums) - 1
```

定义搜索区间。

```python
while left < right:
```

当 `left == right` 时，说明已经定位到最小值。

```python
mid = (left + right) // 2
```

计算中点。

```python
if nums[mid] > nums[right]:
    left = mid + 1
```

如果中点值大于右端值，说明中点在左侧较大的那段，最小值在右边。

```python
else:
    right = mid
```

否则说明 `mid` 到 `right` 是有序的，最小值不可能在 `mid` 右边，但可能就是 `mid`，所以 `right = mid`，不能写成 `mid - 1`。

```python
return nums[left]
```

循环结束时，`left` 指向最小值位置。

#### 关键语法

- `while left < right`：常用于寻找边界值。
- `right = mid`：保留 `mid`，因为 `mid` 可能就是答案。
- `left = mid + 1`：排除 `mid`，因为当 `nums[mid] > nums[right]` 时，`mid` 不可能是最小值。

#### 复杂度分析

- 时间复杂度：`O(log n)`。
- 空间复杂度：`O(1)`。

## 6. #4 寻找两个正序数组的中位数

### 题目描述

给你两个升序数组 `nums1` 和 `nums2`，请你找出这两个数组合并后的中位数。

要求算法时间复杂度为 `O(log(m+n))`。

### 示例

**示例 1：**

```text
输入: nums1 = [1,3], nums2 = [2]
输出: 2.00000
解释: 合并数组为 [1,2,3]，中位数是 2。
```

**示例 2：**

```text
输入: nums1 = [1,2], nums2 = [3,4]
输出: 2.50000
解释: 合并数组为 [1,2,3,4]，中位数是 (2 + 3) / 2 = 2.5。
```

### Python 解法

```python
from typing import List

class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        def get_kth(k):
            index1 = 0
            index2 = 0

            while True:
                if index1 == len(nums1):
                    return nums2[index2 + k - 1]

                if index2 == len(nums2):
                    return nums1[index1 + k - 1]

                if k == 1:
                    return min(nums1[index1], nums2[index2])

                half = k // 2

                new_index1 = min(index1 + half, len(nums1)) - 1
                new_index2 = min(index2 + half, len(nums2)) - 1

                pivot1 = nums1[new_index1]
                pivot2 = nums2[new_index2]

                if pivot1 <= pivot2:
                    k -= new_index1 - index1 + 1
                    index1 = new_index1 + 1
                else:
                    k -= new_index2 - index2 + 1
                    index2 = new_index2 + 1

        total_len = len(nums1) + len(nums2)

        if total_len % 2 == 1:
            return float(get_kth(total_len // 2 + 1))
        else:
            left_mid = get_kth(total_len // 2)
            right_mid = get_kth(total_len // 2 + 1)
            return (left_mid + right_mid) / 2
```

### 代码详细解析

#### 核心思路

中位数问题可以转化为：**寻找两个有序数组中的第 k 小元素**。

如果总长度是奇数：

```text
中位数 = 第 total_len // 2 + 1 小的元素
```

如果总长度是偶数：

```text
中位数 = 第 total_len // 2 小 和 第 total_len // 2 + 1 小 的平均值
```

所以关键是实现 `get_kth(k)`。

#### get_kth 的思想

每次比较两个数组中第 `k // 2` 个候选元素：

- 如果 `nums1` 的候选值更小，说明 `nums1` 当前前面这一段不可能包含第 `k` 小元素，可以全部丢弃；
- 如果 `nums2` 的候选值更小，就丢弃 `nums2` 的那一段。

每次大约丢弃 `k / 2` 个元素，所以复杂度是对数级。

#### 逐行解析

```python
def get_kth(k):
```

定义函数，返回两个数组当前整体的第 `k` 小元素。  
注意这里的 `k` 是从 `1` 开始计数，不是从 `0` 开始。

```python
index1 = 0
index2 = 0
```

两个指针分别指向两个数组当前还没被丢弃的起点。

```python
while True:
```

不断缩小查找范围，直到找到答案。

```python
if index1 == len(nums1):
    return nums2[index2 + k - 1]
```

如果 `nums1` 已经全部被排除，那么第 `k` 小元素只能在 `nums2` 中。

```python
if index2 == len(nums2):
    return nums1[index1 + k - 1]
```

同理，如果 `nums2` 已经全部被排除，就从 `nums1` 中取答案。

```python
if k == 1:
    return min(nums1[index1], nums2[index2])
```

如果要找第 1 小元素，就是两个当前起点中较小的那个。

```python
half = k // 2
```

每轮尝试排除大约 `k // 2` 个元素。

```python
new_index1 = min(index1 + half, len(nums1)) - 1
new_index2 = min(index2 + half, len(nums2)) - 1
```

计算两个数组的候选位置。  
使用 `min` 是为了防止数组长度不够。

```python
pivot1 = nums1[new_index1]
pivot2 = nums2[new_index2]
```

取出候选值。

```python
if pivot1 <= pivot2:
```

如果 `pivot1` 更小，说明 `nums1[index1:new_index1+1]` 这一段都不可能是第 `k` 小元素。

```python
k -= new_index1 - index1 + 1
index1 = new_index1 + 1
```

更新 `k`，并移动 `nums1` 的起点。

```python
else:
    k -= new_index2 - index2 + 1
    index2 = new_index2 + 1
```

否则排除 `nums2` 的一段。

```python
total_len = len(nums1) + len(nums2)
```

计算总长度。

```python
if total_len % 2 == 1:
    return float(get_kth(total_len // 2 + 1))
```

总长度为奇数，返回中间那个数。

```python
else:
    left_mid = get_kth(total_len // 2)
    right_mid = get_kth(total_len // 2 + 1)
    return (left_mid + right_mid) / 2
```

总长度为偶数，返回中间两个数的平均值。

#### 关键语法

- `float(x)`：转换为浮点数。
- `%`：取余，用来判断奇偶。
- `min(a, b)`：返回较小值。
- `while True`：无限循环，通常依靠函数内部的 `return` 结束。
- `k -= x`：等价于 `k = k - x`。

#### 复杂度分析

- 时间复杂度：`O(log(m+n))`。
- 空间复杂度：`O(1)`。

## 1. #20 有效的括号

### 题目描述

给你一个只包含以下字符的字符串 `s`：

```text
'(', ')', '{', '}', '[', ']'
```

请判断这个字符串是否有效。

有效字符串需要满足：

1. 左括号必须用相同类型的右括号闭合；
2. 左括号必须以正确的顺序闭合；
3. 每个右括号都有对应的左括号。

### 示例

**示例 1：**

```text
输入: s = "()"
输出: True
```

**示例 2：**

```text
输入: s = "()[]{}"
输出: True
```

**示例 3：**

```text
输入: s = "(]"
输出: False
```

**示例 4：**

```text
输入: s = "([)]"
输出: False
```

### Python 解法

```python
class Solution:
    def isValid(self, s: str) -> bool:
        stack = []
        pairs = {
            ")": "(",
            "]": "[",
            "}": "{"
        }

        for ch in s:
            if ch in pairs:
                if not stack or stack[-1] != pairs[ch]:
                    return False
                stack.pop()
            else:
                stack.append(ch)

        return not stack
```

### 代码详细解析

#### 核心思路

括号匹配最适合用栈。

栈的特点是：

```text
后进先出
```

例如字符串：

```text
"([])"
```

处理顺序：

1. 遇到 `(`，入栈；
2. 遇到 `[ `，入栈；
3. 遇到 `]`，应该匹配最近的左括号 `[`;
4. 遇到 `)`，应该匹配最近的左括号 `(`。

这正好符合栈的后进先出。

#### 逐行解析

```python
stack = []
```

用列表模拟栈。

```python
pairs = {
    ")": "(",
    "]": "[",
    "}": "{"
}
```

字典保存右括号到左括号的映射。  
例如 `pairs[")"]` 的结果是 `"("`。

```python
for ch in s:
```

遍历字符串中的每一个字符。

```python
if ch in pairs:
```

如果当前字符是右括号，就需要检查栈顶是否是对应的左括号。

```python
if not stack or stack[-1] != pairs[ch]:
    return False
```

两种情况不合法：

1. `not stack`：栈为空，却遇到右括号，说明没有左括号能匹配；
2. `stack[-1] != pairs[ch]`：栈顶左括号类型不匹配。

```python
stack.pop()
```

匹配成功后，把栈顶左括号弹出。

```python
else:
    stack.append(ch)
```

如果当前字符是左括号，就压入栈。

```python
return not stack
```

最后如果栈为空，说明所有左括号都被匹配了。  
如果栈不为空，说明还有左括号没有闭合。

#### 关键语法

- `stack.append(x)`：入栈。
- `stack.pop()`：出栈。
- `stack[-1]`：访问栈顶元素。
- `not stack`：判断列表是否为空。
- `ch in pairs`：判断字符是否是字典中的键。

#### 复杂度分析

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(n)`。

## 2. #155 最小栈

### 题目描述

设计一个支持以下操作的栈，并且能在常数时间内获取栈中的最小元素：

- `push(val)`：将元素压入栈；
- `pop()`：删除栈顶元素；
- `top()`：获取栈顶元素；
- `getMin()`：获取栈中的最小元素。

要求所有操作的时间复杂度都是 `O(1)`。

### 示例

```text
输入:
MinStack minStack = new MinStack()
minStack.push(-2)
minStack.push(0)
minStack.push(-3)
minStack.getMin()   -> -3
minStack.pop()
minStack.top()      -> 0
minStack.getMin()   -> -2
```

### Python 解法

```python
class MinStack:

    def __init__(self):
        self.stack = []
        self.min_stack = []

    def push(self, val: int) -> None:
        self.stack.append(val)

        if not self.min_stack:
            self.min_stack.append(val)
        else:
            self.min_stack.append(min(val, self.min_stack[-1]))

    def pop(self) -> None:
        self.stack.pop()
        self.min_stack.pop()

    def top(self) -> int:
        return self.stack[-1]

    def getMin(self) -> int:
        return self.min_stack[-1]
```

### 代码详细解析

#### 核心思路

普通栈只能快速获取栈顶元素，不能快速获取最小值。

为了解决这个问题，可以额外维护一个辅助栈 `min_stack`。

`min_stack[i]` 表示：当主栈高度为 `i + 1` 时，当前栈中的最小值是多少。

例如依次压入：

```text
-2, 0, -3
```

主栈：

```text
[-2, 0, -3]
```

最小栈：

```text
[-2, -2, -3]
```

这样 `getMin()` 直接返回 `min_stack[-1]` 即可。

#### 逐行解析

```python
self.stack = []
self.min_stack = []
```

- `stack`：普通栈，保存所有元素；
- `min_stack`：辅助栈，保存每个状态下的最小值。

```python
def push(self, val: int) -> None:
```

定义压栈操作。

```python
self.stack.append(val)
```

把元素加入主栈。

```python
if not self.min_stack:
    self.min_stack.append(val)
```

如果最小栈为空，当前元素就是最小值。

```python
else:
    self.min_stack.append(min(val, self.min_stack[-1]))
```

否则当前最小值是：

```text
当前新元素 val
之前最小值 self.min_stack[-1]
```

二者中的较小值。

```python
def pop(self) -> None:
    self.stack.pop()
    self.min_stack.pop()
```

弹出元素时，主栈和最小栈都要弹出，保持两个栈长度一致。

```python
def top(self) -> int:
    return self.stack[-1]
```

返回主栈栈顶元素。

```python
def getMin(self) -> int:
    return self.min_stack[-1]
```

返回当前最小值，也就是最小栈栈顶元素。

#### 关键语法

- `self.xxx`：类对象的成员变量。
- `append` 和 `pop`：列表模拟栈。
- `min(a, b)`：返回两个值中较小的一个。
- `-> None`：表示方法没有返回值。

#### 复杂度分析

- `push`：`O(1)`。
- `pop`：`O(1)`。
- `top`：`O(1)`。
- `getMin`：`O(1)`。
- 空间复杂度：`O(n)`。

## 3. #394 字符串解码

### 题目描述

给你一个经过编码的字符串 `s`，请你返回它解码后的字符串。

编码规则是：

```text
k[encoded_string]
```

表示方括号内部的字符串需要重复 `k` 次。

可以保证输入字符串格式合法，并且数字只表示重复次数。

### 示例

**示例 1：**

```text
输入: s = "3[a]2[bc]"
输出: "aaabcbc"
```

**示例 2：**

```text
输入: s = "3[a2[c]]"
输出: "accaccacc"
```

**示例 3：**

```text
输入: s = "2[abc]3[cd]ef"
输出: "abcabccdcdcdef"
```

### Python 解法

```python
class Solution:
    def decodeString(self, s: str) -> str:
        stack = []
        current_num = 0
        current_str = ""

        for ch in s:
            if ch.isdigit():
                current_num = current_num * 10 + int(ch)
            elif ch == "[":
                stack.append((current_str, current_num))
                current_str = ""
                current_num = 0
            elif ch == "]":
                prev_str, num = stack.pop()
                current_str = prev_str + current_str * num
            else:
                current_str += ch

        return current_str
```

### 代码详细解析

#### 核心思路

这道题有嵌套结构，例如：

```text
3[a2[c]]
```

内部 `2[c]` 要先解码，再处理外层 `3[...]`。  
这种“后遇到的左括号先处理”的结构，适合用栈。

遇到 `[` 时，把当前已经构造的字符串和重复次数保存到栈里。  
遇到 `]` 时，从栈中弹出上一个状态，完成一次解码。

#### 逐行解析

```python
stack = []
current_num = 0
current_str = ""
```

- `stack` 保存之前的字符串和重复次数；
- `current_num` 保存当前读到的数字；
- `current_str` 保存当前层正在构造的字符串。

```python
for ch in s:
```

遍历字符串中的每个字符。

```python
if ch.isdigit():
    current_num = current_num * 10 + int(ch)
```

如果当前字符是数字，就累积成完整数字。

例如 `"12[a]"`：

```text
先读到 1: current_num = 1
再读到 2: current_num = 1 * 10 + 2 = 12
```

```python
elif ch == "[":
```

遇到左括号，说明即将进入一层新的编码内容。

```python
stack.append((current_str, current_num))
```

把进入新层前的字符串和重复次数保存起来。

```python
current_str = ""
current_num = 0
```

重置当前字符串和数字，用来处理括号内部内容。

```python
elif ch == "]":
```

遇到右括号，说明当前层编码内容结束。

```python
prev_str, num = stack.pop()
```

弹出上一层保存的字符串和重复次数。

```python
current_str = prev_str + current_str * num
```

把当前字符串重复 `num` 次，并拼接到上一层字符串后面。

```python
else:
    current_str += ch
```

如果是普通字母，就拼接到当前字符串中。

```python
return current_str
```

遍历结束后，返回最终解码结果。

#### 关键语法

- `ch.isdigit()`：判断字符是否是数字。
- `int(ch)`：把数字字符转成整数。
- `current_str * num`：字符串重复 `num` 次。
- `stack.append((a, b))`：把元组压入栈。
- `prev_str, num = stack.pop()`：元组解包。

#### 复杂度分析

- 时间复杂度：`O(n)` 到 `O(输出字符串长度)`，因为最终需要构造完整结果。
- 空间复杂度：`O(n)`，栈和结果字符串占用空间。

## 4. #739 每日温度

### 题目描述

给你一个整数数组 `temperatures`，表示每天的温度。

请你返回一个数组 `answer`，其中 `answer[i]` 表示对于第 `i` 天，下一个更高温度出现在几天后。

如果之后都不会有更高温度，则 `answer[i] = 0`。

### 示例

**示例 1：**

```text
输入: temperatures = [73,74,75,71,69,72,76,73]
输出: [1,1,4,2,1,1,0,0]
```

**示例 2：**

```text
输入: temperatures = [30,40,50,60]
输出: [1,1,1,0]
```

**示例 3：**

```text
输入: temperatures = [30,60,90]
输出: [1,1,0]
```

### Python 解法

```python
from typing import List

class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        n = len(temperatures)
        answer = [0] * n
        stack = []

        for i, temp in enumerate(temperatures):
            while stack and temperatures[stack[-1]] < temp:
                prev_index = stack.pop()
                answer[prev_index] = i - prev_index

            stack.append(i)

        return answer
```

### 代码详细解析

#### 核心思路

这道题是典型的 **单调栈**。

目标是：对每一天，找它右边第一个比它温度高的日子。

维护一个栈，栈中存放的是下标，并且对应温度保持单调递减。

当当前温度 `temp` 比栈顶下标对应的温度更高时，说明当前这一天就是栈顶那一天等待的“下一个更高温度”。

#### 逐行解析

```python
n = len(temperatures)
answer = [0] * n
stack = []
```

- `n` 是天数；
- `answer` 初始化为全 0；
- `stack` 存储还没有找到更高温度的日期下标。

```python
for i, temp in enumerate(temperatures):
```

同时遍历下标和值。

例如：

```python
temperatures = [73, 74]
```

第一次循环：

```text
i = 0, temp = 73
```

第二次循环：

```text
i = 1, temp = 74
```

```python
while stack and temperatures[stack[-1]] < temp:
```

只要栈不为空，并且当前温度比栈顶那天温度高，就可以为栈顶那天找到答案。

```python
prev_index = stack.pop()
```

弹出栈顶下标。

```python
answer[prev_index] = i - prev_index
```

等待天数 = 当前下标 - 之前下标。

```python
stack.append(i)
```

当前这一天还要等待未来更高温度，所以把当前下标入栈。

```python
return answer
```

返回结果数组。

#### 关键语法

- `enumerate(temperatures)`：同时获取下标和值。
- `stack[-1]`：栈顶下标。
- `temperatures[stack[-1]]`：栈顶下标对应的温度。
- 单调栈通常保存“下标”，不是直接保存值，因为答案往往需要计算距离。

#### 复杂度分析

- 时间复杂度：`O(n)`，每个下标最多入栈一次、出栈一次。
- 空间复杂度：`O(n)`。

## 5. #84 柱状图中最大的矩形

### 题目描述

给你一个整数数组 `heights`，表示柱状图中每个柱子的高度。每个柱子的宽度都为 `1`。

请你计算柱状图中能够形成的最大矩形面积。

### 示例

**示例 1：**

```text
输入: heights = [2,1,5,6,2,3]
输出: 10
解释: 最大矩形由高度 5 和 6 的两根柱子组成，高度取 5，宽度为 2，面积为 10。
```

**示例 2：**

```text
输入: heights = [2,4]
输出: 4
```

### Python 解法

```python
from typing import List

class Solution:
    def largestRectangleArea(self, heights: List[int]) -> int:
        heights = [0] + heights + [0]
        stack = []
        max_area = 0

        for i, height in enumerate(heights):
            while stack and heights[stack[-1]] > height:
                cur_index = stack.pop()
                cur_height = heights[cur_index]
                left_index = stack[-1]
                width = i - left_index - 1
                max_area = max(max_area, cur_height * width)

            stack.append(i)

        return max_area
```

### 代码详细解析

#### 核心思路

这道题是单调栈经典困难题。

对于每根柱子来说，如果把它作为矩形的高度，那么要尽可能向左右扩展，直到遇到比它矮的柱子。

所以问题变成：

```text
对每根柱子，找到它左边第一个比它矮的位置；
对每根柱子，找到它右边第一个比它矮的位置。
```

单调递增栈可以帮助我们在 `O(n)` 时间内完成这个过程。

#### 为什么加两个 0

```python
heights = [0] + heights + [0]
```

左边加 `0`：

- 避免栈为空时难以计算左边界；
- 作为哨兵柱子。

右边加 `0`：

- 强制把栈中剩余柱子全部弹出并计算面积。

#### 逐行解析

```python
heights = [0] + heights + [0]
```

在原数组左右各加一个高度为 `0` 的柱子。

```python
stack = []
max_area = 0
```

- `stack` 存放柱子下标，并保持对应高度单调递增；
- `max_area` 记录最大面积。

```python
for i, height in enumerate(heights):
```

遍历每根柱子。

```python
while stack and heights[stack[-1]] > height:
```

如果当前柱子比栈顶柱子矮，说明栈顶柱子的右边界找到了。  
因为当前柱子就是栈顶柱子右侧第一个更矮的柱子。

```python
cur_index = stack.pop()
cur_height = heights[cur_index]
```

弹出栈顶柱子，并取它的高度。  
现在要计算以 `cur_height` 为高的最大矩形面积。

```python
left_index = stack[-1]
```

弹出后新的栈顶，就是当前柱子左边第一个比它矮的位置。

```python
width = i - left_index - 1
```

矩形宽度计算：

```text
右边界是 i
左边界是 left_index
中间可用宽度 = i - left_index - 1
```

```python
max_area = max(max_area, cur_height * width)
```

更新最大面积。

```python
stack.append(i)
```

把当前柱子下标入栈。

```python
return max_area
```

返回最大矩形面积。

#### 关键语法

- `heights = [0] + heights + [0]`：列表拼接。
- `max(a, b)`：返回较大值。
- 单调栈中保存的是下标，便于计算宽度。
- `width = i - left_index - 1` 是本题最关键的公式。

#### 复杂度分析

- 时间复杂度：`O(n)`，每个元素最多入栈一次、出栈一次。
- 空间复杂度：`O(n)`。

| #153 寻找最小值 | 找旋转断点 |

## 3. 二分查找模板

### 左闭右闭模板

```python
left = 0
right = len(nums) - 1

while left <= right:
    mid = (left + right) // 2

    if nums[mid] == target:
        return mid
    elif nums[mid] < target:
        left = mid + 1
    else:
        right = mid - 1
```

适合普通查找目标值。

### 左闭右开模板

```python
left = 0
right = len(nums)

while left < right:
    mid = (left + right) // 2

    if nums[mid] < target:
        left = mid + 1
    else:
        right = mid
```

适合寻找边界，例如第一个大于等于 `target` 的位置。

## 4. 单调栈模板

### 找右边第一个更大元素

```python
stack = []

for i, x in enumerate(nums):
    while stack and nums[stack[-1]] < x:
        j = stack.pop()
        answer[j] = i - j

    stack.append(i)
```

对应题目：#739 每日温度。

### 找右边第一个更小元素

```python
stack = []

for i, x in enumerate(nums):
    while stack and nums[stack[-1]] > x:
        j = stack.pop()
        # 此时 i 是 j 右边第一个更小元素的位置

    stack.append(i)
```

对应题目：#84 柱状图中最大的矩形。
