### 1. 两数之和

#### 题目描述

给定一个整数数组 `nums` 和一个整数目标值 `target`，请在数组中找出两个数，使它们的和等于 `target`，并返回这两个数的数组下标。

要求：

- 同一个元素不能使用两次。
- 题目保证每组输入只存在一个有效答案。
- 返回下标的顺序通常不作严格要求。

#### 示例

示例 1：

```text
输入：nums = [2, 7, 11, 15], target = 9
输出：[0, 1]
解释：nums[0] + nums[1] = 2 + 7 = 9
```

示例 2：

```text
输入：nums = [3, 2, 4], target = 6
输出：[1, 2]
解释：nums[1] + nums[2] = 2 + 4 = 6
```

#### Python 解法

```python
from typing import List


class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        seen = {}

        for i, num in enumerate(nums):
            need = target - num

            if need in seen:
                return [seen[need], i]

            seen[num] = i

        return []
```

#### 代码详细解析

```python
from typing import List
```

导入 `List` 类型，用于写函数参数和返回值的类型提示。  
在力扣中这不是算法核心，只是让代码含义更清楚。

```python
class Solution:
```

力扣要求把解法写在 `Solution` 类中。  
提交时，力扣会自动创建这个类的对象并调用对应方法。

```python
def twoSum(self, nums: List[int], target: int) -> List[int]:
```

定义题目要求的函数：

- `nums` 是输入数组。
- `target` 是目标和。
- 返回值是一个整数列表，里面放两个下标。

```python
seen = {}
```

创建一个哈希表，也就是 Python 字典。  
它的作用是记录已经遍历过的数字及其下标：

```text
数字 -> 下标
```

例如遍历到 `2` 时，可以记录为：

```python
seen[2] = 0
```

```python
for i, num in enumerate(nums):
```

遍历数组。  
`enumerate(nums)` 会同时拿到：

- `i`：当前元素下标。
- `num`：当前元素值。

例如：

```python
nums = [2, 7, 11, 15]
```

遍历时依次得到：

```text
i = 0, num = 2
i = 1, num = 7
i = 2, num = 11
i = 3, num = 15
```

```python
need = target - num
```

计算当前数字 `num` 需要搭配哪个数字才能等于 `target`。  
例如 `target = 9`，当前 `num = 7`，则：

```text
need = 9 - 7 = 2
```

说明只要前面出现过 `2`，就找到了答案。

```python
if need in seen:
```

判断 `need` 是否已经在哈希表中。  
字典的查找平均时间复杂度是 `O(1)`，所以这一步非常快。

```python
return [seen[need], i]
```

如果 `need` 已经出现过：

- `seen[need]` 是之前那个数的下标。
- `i` 是当前数的下标。

两者相加正好等于 `target`，直接返回。

```python
seen[num] = i
```

如果当前还没有找到答案，就把当前数字和下标存入哈希表，供后面的数字查询。

注意：先判断 `need`，再保存 `num`，可以避免同一个元素被使用两次。  
例如 `nums = [3]，target = 6`，不能把同一个 `3` 用两次。

```python
return []
```

理论上题目保证有答案，所以通常不会执行到这里。  
保留这一行是为了让函数结构完整。

#### 思路总结

暴力法需要枚举所有两两组合，时间复杂度是 `O(n^2)`。  
哈希表解法只需要遍历一遍数组，每次判断“当前数字需要的另一个数是否出现过”，时间复杂度是 `O(n)`。

复杂度：

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

### 49. 字母异位词分组

#### 题目描述

给定一个字符串数组 `strs`，请把字母异位词分到同一组中。

字母异位词指的是：

- 字母种类相同。
- 每个字母出现次数相同。
- 字母顺序可以不同。

例如：

```text
"eat"、"tea"、"ate"
```

它们都由 `a`、`e`、`t` 组成，所以属于同一组。

#### 示例

示例 1：

```text
输入：strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
输出：[["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
解释：同一组中的字符串排序后相同。
```

示例 2：

```text
输入：strs = [""]
输出：[[""]]
```

示例 3：

```text
输入：strs = ["a"]
输出：[["a"]]
```

#### Python 解法

```python
from typing import List
from collections import defaultdict


class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        groups = defaultdict(list)

        for s in strs:
            key = ''.join(sorted(s))
            groups[key].append(s)

        return list(groups.values())
```

普通字典写法可能需要：

```python

    groups[key] = []

```

```python

```

- 输入是字符串列表 `strs`。
- 输出是二维列表，每个小列表是一组字母异位词。


键是某个字符串排序后的结果，值是属于这一组的所有原字符串。

例如：

```text

"ate" 排序后也是 "aet"
```

因此它们都会放到 `groups["aet"]` 里面。



分开看：

```python

```

会把字符串 `s` 中的字符排序，返回一个字符列表。

例如：

```python

```

结果是：

```python

```

再看：

```python

```

表示用空字符串把字符列表拼接起来。  
所以：

```python

```

```python

```

因此：

```python

```

就是把每个字符串变成它的“标准形式”。  
同一组字母异位词的标准形式一定相同。


把原始字符串 `s` 加入对应分组。  
注意保存的是原字符串，不是排序后的字符串。

例如：

```python
groups["aet"] = ["eat", "tea", "ate"]
```


#### 思路总结

字母异位词的本质是“字符组成相同”。  
把每个字符串排序后，相同组成的字符串会变成同一个形式，因此可以用排序后的字符串作为哈希表的键。

复杂度：

设：

- `n` 是字符串个数。
- `k` 是单个字符串的平均长度。

则：

- 时间复杂度：`O(n * k log k)`，因为每个字符串都要排序。
- 空间复杂度：`O(n * k)`，用于保存分组结果。

### 128. 最长连续序列

#### 题目描述

给定一个未排序的整数数组 `nums`，请找出数字连续的最长序列长度。

要求算法的时间复杂度为 `O(n)`。

连续序列指的是数值连续，而不是数组中的位置连续。

例如：

```text
nums = [100, 4, 200, 1, 3, 2]
```

其中最长连续序列是：

```text
[1, 2, 3, 4]
```

长度为 `4`。

#### 示例

示例 1：

```text
输入：nums = [100, 4, 200, 1, 3, 2]
输出：4
解释：最长连续序列是 [1, 2, 3, 4]。
```

示例 2：

```text
输入：nums = [0,3,7,2,5,8,4,6,0,1]
输出：9
解释：最长连续序列是 [0,1,2,3,4,5,6,7,8]。
```

#### Python 解法

```python
from typing import List


class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        num_set = set(nums)
        longest = 0

        for num in num_set:
            if num - 1 not in num_set:
                current = num
                length = 1

                while current + 1 in num_set:
                    current += 1
                    length += 1

                longest = max(longest, length)

        return longest
```

#### 代码详细解析

```python
from typing import List
```

导入类型提示。

```python
class Solution:
```

定义力扣要求的类。

```python
def longestConsecutive(self, nums: List[int]) -> int:
```

定义函数：

- 输入是整数数组 `nums`。
- 输出是最长连续序列的长度。

```python
num_set = set(nums)
```

把数组转换为集合。  
集合有两个重要作用：

1. 自动去重。
2. 支持平均 `O(1)` 时间判断某个数字是否存在。

例如：

```python
nums = [0, 0, 1, 2]
num_set = {0, 1, 2}
```

```python
longest = 0
```

记录目前找到的最长连续序列长度。

```python
for num in num_set:
```

遍历集合中的每个数字。  
这里遍历集合而不是原数组，可以避免重复数字造成重复计算。

```python
if num - 1 not in num_set:
```

判断 `num` 是否是一个连续序列的起点。

如果 `num - 1` 不存在，说明没有更小的数字可以接在 `num` 前面，`num` 就是起点。

例如：

```text
1, 2, 3, 4
```

对于 `1`：

```text
1 - 1 = 0 不存在
```

所以 `1` 是起点。

对于 `2`：

```text
2 - 1 = 1 存在
```

所以 `2` 不是起点，不需要从 `2` 开始数。

这样可以保证每个连续序列只被计算一次。

```python
current = num
```

用 `current` 表示当前正在检查的数字。

```python
length = 1
```

当前连续序列至少包含起点 `num`，所以初始长度是 `1`。

```python
while current + 1 in num_set:
```

只要下一个连续数字存在，就继续向后扩展序列。

例如当前是 `1`，如果 `2` 在集合中，就继续找 `3`。

```python
current += 1
```

把当前数字移动到下一个数字。

```python
length += 1
```

连续序列长度加一。

```python
longest = max(longest, length)
```

用当前序列长度更新全局最长长度。

```python
return longest
```

返回最终答案。

#### 思路总结

关键点是只从“连续序列的起点”开始统计。  
如果每个数字都向后统计，可能会退化成 `O(n^2)`。  
通过 `num - 1 not in num_set` 找起点，可以保证每个数字最多被访问有限次，整体是 `O(n)`。

复杂度：

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

### 283. 移动零

#### 题目描述

给定一个整数数组 `nums`，请将所有 `0` 移动到数组末尾，同时保持非零元素的相对顺序不变。

要求：

- 必须在原数组上操作。
- 不能复制一个额外数组。
- 尽量减少操作次数。

#### 示例

示例 1：

```text
输入：nums = [0, 1, 0, 3, 12]
输出：[1, 3, 12, 0, 0]
```

示例 2：

```text
输入：nums = [0]
输出：[0]
```

#### Python 解法

```python
from typing import List


class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        slow = 0

        for fast in range(len(nums)):
            if nums[fast] != 0:
                nums[slow], nums[fast] = nums[fast], nums[slow]
                slow += 1
```

#### 代码详细解析

```python
from typing import List
```

导入类型提示。

```python
class Solution:
```

定义力扣要求的解法类。

```python
def moveZeroes(self, nums: List[int]) -> None:
```

定义函数。  
本题要求原地修改数组，所以函数不需要返回新数组，返回值是 `None`。

```python
slow = 0
```

定义慢指针 `slow`。  
它表示“下一个非零元素应该放到的位置”。

换句话说：

- `slow` 左边都是已经处理好的非零元素。
- `slow` 当前指向的位置等待放入下一个非零元素。

```python
for fast in range(len(nums)):
```

定义快指针 `fast`，从左到右扫描整个数组。  
`range(len(nums))` 会生成从 `0` 到 `len(nums) - 1` 的下标。

例如数组长度是 `5`：

```python
range(5)
```

对应下标：

```text
0, 1, 2, 3, 4
```

```python
if nums[fast] != 0:
```

如果快指针遇到的是非零元素，就应该把它移动到前面。

```python
nums[slow], nums[fast] = nums[fast], nums[slow]
```

交换 `slow` 和 `fast` 位置的元素。  
这是 Python 的多变量赋值语法，可以不借助临时变量完成交换。

例如：

```python
a, b = b, a
```

本题中：

- `nums[fast]` 是当前遇到的非零元素。
- `nums[slow]` 是下一个应该放非零元素的位置。

交换后，非零元素被放到了前面。

```python
slow += 1
```

因为已经放好了一个非零元素，所以 `slow` 向右移动一位，等待下一个非零元素。

#### 思路总结

用快指针扫描数组，用慢指针记录非零元素应该放的位置。  
每遇到一个非零元素，就把它交换到 `slow` 位置。  
扫描结束后，所有非零元素都在前面，所有零自然被挤到后面。

复杂度：

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### 11. 盛最多水的容器

#### 题目描述

给定一个长度为 `n` 的整数数组 `height`。  
数组中的每个元素代表一条垂直线的高度，第 `i` 条线的两个端点为 `(i, 0)` 和 `(i, height[i])`。

从中选择两条线，与 x 轴共同组成一个容器。  
请找出这个容器能够容纳的最大水量。

容器面积计算方式：

```text
面积 = 两条线中较短的高度 × 两条线之间的距离
```

#### 示例

示例 1：

```text
输入：height = [1,8,6,2,5,4,8,3,7]
输出：49
解释：选择下标 1 和下标 8，高度分别为 8 和 7，宽度为 7，面积为 7 × 7 = 49。
```

示例 2：

```text
输入：height = [1,1]
输出：1
```

#### Python 解法

```python
from typing import List


class Solution:
    def maxArea(self, height: List[int]) -> int:
        left = 0
        right = len(height) - 1
        ans = 0

        while left < right:
            width = right - left
            h = min(height[left], height[right])
            ans = max(ans, width * h)

            if height[left] < height[right]:
                left += 1
            else:
                right -= 1

        return ans
```

```python

```

导入类型提示。

```python

```

定义力扣要求的解法类。

```python

```

定义函数：

- 输入 `height` 是高度数组。
- 返回最大容器面积。

```python

```

左指针从数组最左边开始。

```python
right = len(height) - 1
```

右指针从数组最右边开始。

```python
ans = 0
```

记录目前找到的最大面积。

```python

```

只要左指针在右指针左边，就可以形成一个容器。

```python

```

计算容器宽度。  
两条线之间的距离就是下标差。

```python

```

计算容器有效高度。  
水的高度由较短的那条线决定，因为水会从短板溢出。

```python

```

计算当前容器面积，并更新最大值。

```python

```

比较左右两条线的高度。  
如果左边更短，那么当前容器的短板是左边。

```python

```

原因是：宽度接下来一定会变小，如果继续保留较短的左边界，面积不可能因为右边移动而变大。  
只有尝试换掉短板，才可能找到更大的面积。

```python

```

```python

```

```python
return ans
```

返回最大面积。

#### 思路总结

初始时使用最宽的容器。  
每一步面积由“宽度”和“短板高度”决定。  
宽度缩小不可避免，因此应该移动较短的一边，尝试提高短板高度。

复杂度：

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### 15. 三数之和

#### 题目描述

给定一个整数数组 `nums`，请找出所有不重复的三元组：

```text
[nums[i], nums[j], nums[k]]
```

满足：

```text
i、j、k 互不相同
nums[i] + nums[j] + nums[k] == 0
```

答案中不能包含重复三元组。

#### 示例

示例 1：

```text
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = -1 + 0 + 1 = 0
nums[1]、nums[2]、nums[4] 可以组成 [-1,0,1]
去重后答案为 [[-1,-1,2],[-1,0,1]]
```

示例 2：

```text
输入：nums = [0,1,1]
输出：[]
解释：不存在和为 0 的三元组。
```

示例 3：

```text
输入：nums = [0,0,0]
输出：[[0,0,0]]
```

#### Python 解法

```python
from typing import List


class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        ans = []
        n = len(nums)

        for i in range(n - 2):
            if i > 0 and nums[i] == nums[i - 1]:
                continue

            if nums[i] > 0:
                break

            left = i + 1
            right = n - 1

            while left < right:
                total = nums[i] + nums[left] + nums[right]

                if total == 0:
                    ans.append([nums[i], nums[left], nums[right]])

                    left += 1
                    right -= 1

                    while left < right and nums[left] == nums[left - 1]:
                        left += 1

                    while left < right and nums[right] == nums[right + 1]:
                        right -= 1

                elif total < 0:
                    left += 1
                else:
                    right -= 1

        return ans
```

### 42. 接雨水

#### 题目描述

给定 `n` 个非负整数表示柱子的高度图。  
每个柱子的宽度为 `1`，请计算下雨后这些柱子最多能接多少水。

对某个位置来说，它能接的水量取决于：

```text
min(左边最高柱子, 右边最高柱子) - 当前柱子高度
```

如果这个值小于等于 `0`，则该位置不能接水。

#### 示例

示例 1：

```text

解释：这些柱子一共可以接 6 个单位的水。
```

示例 2：

```text
输出：9
```

#### Python 解法

```python
from typing import List


class Solution:
    def trap(self, height: List[int]) -> int:
        left = 0
        right = len(height) - 1
        left_max = 0
        right_max = 0
        ans = 0

        while left < right:
            if height[left] < height[right]:
                if height[left] >= left_max:
                    left_max = height[left]
                else:
                    ans += left_max - height[left]
                left += 1
            else:
                if height[right] >= right_max:
                    right_max = height[right]
                else:
                    ans += right_max - height[right]
                right -= 1

        return ans
```

### 3. 无重复字符的最长子串

#### 题目描述

给定一个字符串 `s`，请找出其中不含重复字符的最长子串的长度。

注意：

- 子串必须是连续的。
- 子序列不要求连续，但本题要求的是子串，所以必须连续。

#### 示例

示例 1：

```text
输入：s = "abcabcbb"
输出：3
解释：最长无重复字符子串是 "abc"，长度为 3。
```

示例 2：

```text
输入：s = "bbbbb"
输出：1
解释：最长无重复字符子串是 "b"，长度为 1。
```

示例 3：

```text
输入：s = "pwwkew"
输出：3
解释：最长无重复字符子串是 "wke"，长度为 3。
注意："pwke" 不是子串，因为它在原字符串中不连续。
```

#### Python 解法

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        last_pos = {}
        left = 0
        ans = 0

        for right, ch in enumerate(s):
            if ch in last_pos and last_pos[ch] >= left:
                left = last_pos[ch] + 1

            last_pos[ch] = right
            ans = max(ans, right - left + 1)

        return ans
```

### 438. 找到字符串中所有字母异位词

#### 题目描述

给定两个字符串 `s` 和 `p`，请找出 `s` 中所有是 `p` 的字母异位词的子串，返回这些子串的起始下标。

字母异位词要求：

- 字符种类相同。
- 每个字符出现次数相同。
- 字符顺序可以不同。

由于要找的是 `s` 中的子串，所以匹配片段必须连续。

#### 示例

示例 1：

```text
输入：s = "cbaebabacd", p = "abc"
输出：[0, 6]
解释：
s[0:3] = "cba"，是 "abc" 的字母异位词。
s[6:9] = "bac"，是 "abc" 的字母异位词。
```

示例 2：

```text
输入：s = "abab", p = "ab"
输出：[0, 1, 2]
解释：
s[0:2] = "ab"
s[1:3] = "ba"
s[2:4] = "ab"
它们都是 "ab" 的字母异位词。
```

#### Python 解法

```python
from typing import List


class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        m = len(s)
        n = len(p)

        if n > m:
            return []

        need = [0] * 26
        window = [0] * 26
        ans = []

        for i in range(n):
            need[ord(p[i]) - ord('a')] += 1
            window[ord(s[i]) - ord('a')] += 1

        if window == need:
            ans.append(0)

        for right in range(n, m):
            window[ord(s[right]) - ord('a')] += 1
            left = right - n
            window[ord(s[left]) - ord('a')] -= 1

            if window == need:
                ans.append(left + 1)

        return ans
```
