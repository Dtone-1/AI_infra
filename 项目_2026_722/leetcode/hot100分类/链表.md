## 1. #160 相交链表

### 题目描述
给你两个单链表 `headA` 和 `headB`，请你找出并返回这两个链表相交的起始节点。如果两个链表没有相交，返回 `None`。

这里的“相交”指的是两个链表在某个节点开始后面共用同一段节点，也就是说后面的节点是同一批节点对象，而不是值相同。

### 示例

**示例 1：**

```text
A: 4 -> 1 -> 8 -> 4 -> 5
B: 5 -> 6 -> 1 -> 8 -> 4 -> 5
相交起点: 8
输出: 指向值为 8 的节点
```

**示例 2：**

```text
A: 1 -> 9 -> 1 -> 2 -> 4
B: 3 -> 2 -> 4
相交起点: 2
输出: 指向值为 2 的节点
```

**示例 3：**

```text
A: 2 -> 6 -> 4
B: 1 -> 5
输出: None
解释: 两个链表不相交
```

### Python 解法

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> ListNode:
        pA = headA
        pB = headB

        while pA != pB:
            pA = pA.next if pA else headB
            pB = pB.next if pB else headA

        return pA
```

### 代码详细解析

#### 思路分析
这是这道题最经典的“双指针”解法。

假设：
- 链表 A 长度为 `a + c`
- 链表 B 长度为 `b + c`
- 其中 `c` 是公共尾部长度

两个指针：
- `pA` 先走 A，再走 B
- `pB` 先走 B，再走 A

这样两个指针总共都会走 `a + b + c` 这一套路径。如果有交点，它们一定会在交点相遇；如果没有交点，它们最终会一起走到 `None`。

#### 逐行解析
- `pA = headA`：让指针 `pA` 从链表 A 的头结点开始。
- `pB = headB`：让指针 `pB` 从链表 B 的头结点开始。
- `while pA != pB:`：只要两个指针没有指向同一个节点，就继续走。
  - 这里比较的是“节点对象是否相同”，不是节点值是否相同。
- `pA = pA.next if pA else headB`：
  - 如果 `pA` 还没走到末尾，就继续往后走；
  - 如果 `pA` 已经是 `None`，说明 A 走完了，就切换到 B 的头部继续走。
- `pB = pB.next if pB else headA`：
  - 与 `pA` 同理。
- `return pA`：
  - 如果相交，返回相交节点；
  - 如果不相交，最后 `pA` 和 `pB` 都会是 `None`，返回 `None`。

#### 关键语法
- `x if 条件 else y`：Python 三元表达式。
- `pA != pB`：比较两个变量是否引用同一个节点对象。

## 2. #206 反转链表

### 题目描述
给你一个单链表的头节点 `head`，请你将链表反转，并返回反转后的头节点。

### 示例

**示例 1：**

```text
输入: 1 -> 2 -> 3 -> 4 -> 5
输出: 5 -> 4 -> 3 -> 2 -> 1
```

**示例 2：**

```text
输入: 1 -> 2
输出: 2 -> 1
```

**示例 3：**

```text
输入: 空链表
输出: 空链表
```

### Python 解法

```python
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def reverseList(self, head: ListNode) -> ListNode:
        prev = None
        curr = head

        while curr:
            nxt = curr.next
            curr.next = prev
            prev = curr
            curr = nxt

        return prev
```

### 代码详细解析

#### 思路分析
反转链表的核心，就是把每个节点的 `next` 指针方向反过来。

遍历链表时，我们需要保存三个量：
- `prev`：当前节点反转后应该连向谁
- `curr`：当前正在处理的节点
- `nxt`：提前保存当前节点的下一个节点，防止断链

#### 逐行解析
- `prev = None`：一开始反转后的前驱节点为空，因为原链表头结点反转后会变成尾结点，尾结点的 `next` 应该是 `None`。
- `curr = head`：当前处理节点从头开始。
- `while curr:`：只要当前节点不为空，就继续反转。
- `nxt = curr.next`：先保存后继节点，防止修改 `curr.next` 后找不到后面的链表。
- `curr.next = prev`：把当前节点的指针反转，指向前一个节点。
- `prev = curr`：更新 `prev`，让它移动到当前节点。
- `curr = nxt`：继续处理原链表中的下一个节点。
- `return prev`：循环结束时，`prev` 指向新的头结点。

#### 关键语法
- `while curr:`：只要 `curr` 不为 `None`，循环就继续。
- 链表题里，最重要的是“改指针前先保存下一跳”。

## 3. #234 回文链表

### 题目描述
给你一个单链表的头节点 `head`，请判断该链表是否为回文链表。如果正着读和反着读完全一致，就返回 `True`，否则返回 `False`。

### 示例

**示例 1：**

```text
输入: 1 -> 2 -> 2 -> 1
输出: True
```

**示例 2：**

```text
输入: 1 -> 2
输出: False
```

### Python 解法

```python
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def isPalindrome(self, head: ListNode) -> bool:
        slow = fast = head

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        prev = None
        curr = slow
        while curr:
            nxt = curr.next
            curr.next = prev
            prev = curr
            curr = nxt

        left = head
        right = prev
        while right:
            if left.val != right.val:
                return False
            left = left.next
            right = right.next

        return True
```

### 代码详细解析

#### 思路分析
经典做法分三步：
1. 用快慢指针找到链表中点。
2. 反转后半部分链表。
3. 从头和后半部分的头同时比较值是否相同。

#### 逐行解析
- `slow = fast = head`：快慢指针同时从头出发。
- `while fast and fast.next:`：
  - `fast` 每次走两步；
  - `slow` 每次走一步；
  - 当循环结束时，`slow` 会到达中间位置。
- 下面一段反转链表代码：
  - `prev = None`：反转时的前驱节点。
  - `curr = slow`：从中点开始反转后半段。
  - `nxt = curr.next`：保存下一个节点。
  - `curr.next = prev`：反转指针。
  - `prev = curr`、`curr = nxt`：向后推进。
- `left = head`：左侧从原链表头部开始。
- `right = prev`：右侧从反转后的后半段头部开始。
- `while right:`：依次比较。
  - 为什么只判断 `right`？
  - 因为后半段长度小于等于前半段，比较到后半段结束就够了。
- `if left.val != right.val:`：只要有一个值不同，就不是回文。
- `return True`：都比较完仍然相同，说明是回文。

#### 关键语法
- `slow = fast = head`：链式赋值。
- `fast and fast.next`：防止空指针错误，是链表快慢指针的常见写法。

## 4. #141 环形链表

### 题目描述
给你一个链表的头节点 `head`，判断链表中是否存在环。如果某个节点可以通过不断沿着 `next` 指针再次回到之前访问过的节点，就说明存在环。

### 示例

**示例 1：**

```text
输入: 3 -> 2 -> 0 -> -4，尾部连接到值为 2 的节点
输出: True
```

**示例 2：**

```text
输入: 1 -> 2，尾部连接到头节点
输出: True
```

**示例 3：**

```text
输入: 1 -> None
输出: False
```

### Python 解法

```python
class Solution:
    def hasCycle(self, head: ListNode) -> bool:
        slow = fast = head

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow == fast:
                return True

        return False
```

### 代码详细解析

#### 思路分析
使用 Floyd 判圈算法，也叫“快慢指针”。

- 慢指针每次走一步
- 快指针每次走两步

如果链表有环，那么快指针最终一定会追上慢指针；如果没有环，快指针会先走到 `None`。

#### 逐行解析
- `slow = fast = head`：两个指针都从头结点出发。
- `while fast and fast.next:`：
  - 要保证 `fast` 和 `fast.next` 都存在，才可以让 `fast` 走两步。
- `slow = slow.next`：慢指针走一步。
- `fast = fast.next.next`：快指针走两步。
- `if slow == fast:`：如果两个指针相遇，说明有环。
- `return False`：循环正常结束，说明快指针到头了，没有环。

#### 关键语法
- `==` 用在这里，本质是比较两个节点对象是否是同一个节点。

## 5. #142 环形链表 II

### 题目描述
给你一个链表头节点 `head`，如果链表中有环，请返回入环的第一个节点；如果没有环，返回 `None`。

### 示例

**示例 1：**

```text
输入: 3 -> 2 -> 0 -> -4，尾部连接到值为 2 的节点
输出: 指向值为 2 的节点
```

**示例 2：**

```text
输入: 1 -> 2，尾部连接到值为 1 的节点
输出: 指向值为 1 的节点
```

**示例 3：**

```text
输入: 1 -> None
输出: None
```

### Python 解法

```python
class Solution:
    def detectCycle(self, head: ListNode) -> ListNode:
        slow = fast = head

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow == fast:
                p = head
                while p != slow:
                    p = p.next
                    slow = slow.next
                return p

        return None
```

### 代码详细解析

#### 思路分析
这道题是在“是否有环”的基础上，再进一步找“环的入口”。

Floyd 算法有一个重要结论：
- 快慢指针第一次相遇后；
- 一个指针从头节点出发，另一个指针从相遇点出发；
- 两者每次都走一步；
- 它们会在入环点再次相遇。

#### 逐行解析
- 前半段 `while fast and fast.next:` 和上一题完全一样，用来判断是否有环。
- `if slow == fast:`：说明有环，并且当前相遇。
- `p = head`：新建一个指针 `p`，从头开始。
- `while p != slow:`：
  - `p` 从头走；
  - `slow` 从相遇点走；
  - 每次都走一步。
- `p = p.next`、`slow = slow.next`：同步前进。
- `return p`：两者相遇处就是入环点。
- 如果整个快慢指针过程没有相遇，就 `return None`。

#### 关键语法
- 这里仍然是“双指针 + 数学关系”的经典题。
- 代码虽然短，但结论要理解透：第一次相遇点不是入口，但可以帮助找到入口。

## 6. #21 合并两个有序链表

### 题目描述
给你两个已经按非递减顺序排列的链表 `list1` 和 `list2`，请将它们合并为一个新的有序链表，并返回合并后链表的头节点。

### 示例

**示例 1：**

```text
输入: list1 = 1 -> 2 -> 4, list2 = 1 -> 3 -> 4
输出: 1 -> 1 -> 2 -> 3 -> 4 -> 4
```

**示例 2：**

```text
输入: list1 = 空, list2 = 空
输出: 空
```

**示例 3：**

```text
输入: list1 = 空, list2 = 0
输出: 0
```

### Python 解法

```python
class Solution:
    def mergeTwoLists(self, list1: ListNode, list2: ListNode) -> ListNode:
        dummy = ListNode(0)
        cur = dummy

        while list1 and list2:
            if list1.val <= list2.val:
                cur.next = list1
                list1 = list1.next
            else:
                cur.next = list2
                list2 = list2.next
            cur = cur.next

        cur.next = list1 if list1 else list2
        return dummy.next
```

### 代码详细解析

#### 思路分析
使用“虚拟头结点 + 双指针”。

因为两个链表本身已经有序，所以每次只需要比较当前两个头节点，把更小的那个接到结果链表后面即可。

#### 逐行解析
- `dummy = ListNode(0)`：创建虚拟头结点，方便统一处理。
- `cur = dummy`：`cur` 指向当前结果链表的末尾。
- `while list1 and list2:`：只要两个链表都还有节点，就继续比较。
- `if list1.val <= list2.val:`：如果 `list1` 当前值更小（或相等），先接它。
- `cur.next = list1`：把 `list1` 当前节点接到结果链表后面。
- `list1 = list1.next`：`list1` 向后走。
- `else:` 分支同理，把 `list2` 接过去。
- `cur = cur.next`：结果链表尾指针向后移动。
- `cur.next = list1 if list1 else list2`：
  - 如果某一个链表已经空了，直接把另一个剩余部分整体接到后面。
- `return dummy.next`：返回真正的头结点，跳过虚拟头。

#### 关键语法
- `dummy`：链表题中非常常见，能减少头结点特殊处理。
- `list1 if list1 else list2`：谁没空就接谁。

## 7. #2 两数相加

### 题目描述
给你两个非空链表，分别表示两个非负整数。每个节点存储一位数字，并且数字是按“逆序”存储的，也就是个位在前。请你计算这两个数的和，并仍然用链表的形式逆序返回。

你可以假设除了数字 0 本身之外，这两个数都不会以前导 0 开头。

### 示例

**示例 1：**

```text
输入: l1 = 2 -> 4 -> 3, l2 = 5 -> 6 -> 4
解释: 342 + 465 = 807
输出: 7 -> 0 -> 8
```

**示例 2：**

```text
输入: l1 = 0, l2 = 0
输出: 0
```

**示例 3：**

```text
输入: l1 = 9 -> 9 -> 9 -> 9 -> 9 -> 9 -> 9
      l2 = 9 -> 9 -> 9 -> 9
输出: 8 -> 9 -> 9 -> 9 -> 0 -> 0 -> 0 -> 1
```

### Python 解法

```python
class Solution:
    def addTwoNumbers(self, l1: ListNode, l2: ListNode) -> ListNode:
        dummy = ListNode(0)
        cur = dummy
        carry = 0

        while l1 or l2 or carry:
            x = l1.val if l1 else 0
            y = l2.val if l2 else 0
            total = x + y + carry

            carry = total // 10
            cur.next = ListNode(total % 10)
            cur = cur.next

            if l1:
                l1 = l1.next
            if l2:
                l2 = l2.next

        return dummy.next
```

### 代码详细解析

#### 思路分析
这道题本质上是在模拟小学竖式加法。

每一位：
- 当前位结果 = `(x + y + carry) % 10`
- 进位 = `(x + y + carry) // 10`

#### 逐行解析
- `dummy = ListNode(0)`：虚拟头结点。
- `cur = dummy`：结果链表尾指针。
- `carry = 0`：记录进位。
- `while l1 or l2 or carry:`：
  - 只要任意一个链表还有节点，或者还有进位，就继续算。
- `x = l1.val if l1 else 0`：如果 `l1` 当前有节点，取值；否则按 0 处理。
- `y = l2.val if l2 else 0`：同理。
- `total = x + y + carry`：当前位总和。
- `carry = total // 10`：十位部分作为新的进位。
- `cur.next = ListNode(total % 10)`：个位部分作为当前新节点。
- `cur = cur.next`：尾指针后移。
- `if l1:` / `if l2:`：如果链表还没结束，就向后走。
- `return dummy.next`：返回结果链表头结点。

#### 关键语法
- `//`：整除，得到进位。
- `%`：取余，得到当前位数字。
- `while l1 or l2 or carry`：这是本题循环条件的关键。

## 8. #19 删除链表的倒数第 N 个结点

### 题目描述
给你一个链表头节点 `head`，请删除链表中倒数第 `n` 个节点，并返回删除后的头节点。

### 示例

**示例 1：**

```text
输入: 1 -> 2 -> 3 -> 4 -> 5, n = 2
输出: 1 -> 2 -> 3 -> 5
```

**示例 2：**

```text
输入: 1, n = 1
输出: 空链表
```

**示例 3：**

```text
输入: 1 -> 2, n = 1
输出: 1
```

### Python 解法

```python
class Solution:
    def removeNthFromEnd(self, head: ListNode, n: int) -> ListNode:
        dummy = ListNode(0, head)
        fast = slow = dummy

        for _ in range(n + 1):
            fast = fast.next

        while fast:
            fast = fast.next
            slow = slow.next

        slow.next = slow.next.next
        return dummy.next
```

### 代码详细解析

#### 思路分析
使用“快慢指针”。

目标是让 `fast` 和 `slow` 保持 `n + 1` 个节点的距离，这样当 `fast` 到达末尾时，`slow` 恰好停在“待删除节点的前一个节点”。

#### 逐行解析
- `dummy = ListNode(0, head)`：
  - 加虚拟头结点，方便处理“删除头节点”的情况。
- `fast = slow = dummy`：两个指针都从虚拟头开始。
- `for _ in range(n + 1):`：
  - 先让 `fast` 走 `n + 1` 步。
  - `range(n + 1)` 会生成 `0` 到 `n`，一共 `n + 1` 次循环。
- `fast = fast.next`：`fast` 前进。
- `while fast:`：只要 `fast` 还没到结尾，就让两个指针一起走。
- `slow.next = slow.next.next`：
  - `slow.next` 是要删除的节点；
  - 让它跳过这个节点，直接指向下下个节点。
- `return dummy.next`：返回新链表头。

#### 关键语法
- `range(n + 1)`：循环 `n + 1` 次。
- `ListNode(0, head)`：构造节点时同时设置 `val` 和 `next`。

## 9. #24 两两交换链表中的节点

### 题目描述
给你一个链表，请你每两个相邻节点交换一次，并返回交换后的链表头节点。你不能只修改节点值，而是要真正交换节点本身。

### 示例

**示例 1：**

```text
输入: 1 -> 2 -> 3 -> 4
输出: 2 -> 1 -> 4 -> 3
```

**示例 2：**

```text
输入: 空链表
输出: 空链表
```

**示例 3：**

```text
输入: 1
输出: 1
```

### Python 解法

```python
class Solution:
    def swapPairs(self, head: ListNode) -> ListNode:
        dummy = ListNode(0)
        dummy.next = head
        cur = dummy

        while cur.next and cur.next.next:
            node1 = cur.next
            node2 = cur.next.next

            cur.next = node2
            node1.next = node2.next
            node2.next = node1

            cur = node1

        return dummy.next
```

### 代码详细解析

#### 思路分析
每次处理两个节点：
- `node1`
- `node2`

将：
`cur -> node1 -> node2 -> next`
变成：
`cur -> node2 -> node1 -> next`

#### 逐行解析
- `dummy = ListNode(0)`：建立虚拟头节点。
- `dummy.next = head`：让虚拟头连上原链表。
- `cur = dummy`：`cur` 表示当前这一组待交换节点之前的那个节点。
- `while cur.next and cur.next.next:`：
  - 必须保证后面至少还有两个节点，才能交换。
- `node1 = cur.next`：第一节点。
- `node2 = cur.next.next`：第二节点。
- `cur.next = node2`：先把前驱连到第二个节点。
- `node1.next = node2.next`：让第一个节点跳过第二个，连到后面的节点。
- `node2.next = node1`：让第二个节点再连回第一个，完成交换。
- `cur = node1`：交换完成后，`node1` 变成这一组的后一个节点，下一轮从它后面继续处理。
- `return dummy.next`：返回新的头结点。

#### 关键语法
- `while cur.next and cur.next.next` 是链表题中的典型防空写法。

## 10. #25 K 个一组翻转链表

### 题目描述
给你一个链表头节点 `head`，每 `k` 个节点作为一组进行翻转，返回翻转后的链表。如果最后剩余的节点数量不足 `k` 个，则保持原样。

你不能只改变节点值，必须实际交换节点。

### 示例

**示例 1：**

```text
输入: 1 -> 2 -> 3 -> 4 -> 5, k = 2
输出: 2 -> 1 -> 4 -> 3 -> 5
```

**示例 2：**

```text
输入: 1 -> 2 -> 3 -> 4 -> 5, k = 3
输出: 3 -> 2 -> 1 -> 4 -> 5
```

### Python 解法

```python
class Solution:
    def reverseKGroup(self, head: ListNode, k: int) -> ListNode:
        dummy = ListNode(0)
        dummy.next = head
        pre = dummy

        while True:
            tail = pre
            for _ in range(k):
                tail = tail.next
                if not tail:
                    return dummy.next

            nxt = tail.next
            start = pre.next

            prev = nxt
            curr = start
            while curr != nxt:
                temp = curr.next
                curr.next = prev
                prev = curr
                curr = temp

            pre.next = tail
            pre = start
```

### 代码详细解析

#### 思路分析
这道题可以理解为：
- 每次截出一段长度为 `k` 的子链表；
- 把这段链表反转；
- 再接回原链表。

#### 逐行解析
- `dummy = ListNode(0)`：虚拟头结点。
- `pre = dummy`：`pre` 指向当前分组的前一个节点。
- `while True:`：不断处理一组一组的节点。
- `tail = pre`：用 `tail` 去找这一组的尾部。
- `for _ in range(k):`：尝试往后走 `k` 步。
- `if not tail:`：如果不足 `k` 个节点，直接返回。
- `nxt = tail.next`：记录这一组后面的第一个节点。
- `start = pre.next`：这一组的起点。

反转部分：
- `prev = nxt`：反转后，这组最后一个节点要连接到 `nxt`，所以前驱初始设为 `nxt`。
- `curr = start`：从这一组开头开始反转。
- `while curr != nxt:`：只反转这一组，不越界到后面。
- `temp = curr.next`：保存下一个节点。
- `curr.next = prev`：反转指针。
- `prev = curr`、`curr = temp`：向后推进。

接回链表：
- `pre.next = tail`：反转后，这一组新的头节点就是原来的 `tail`。
- `pre = start`：反转后，原来的 `start` 变成这一组的尾节点，下一轮从它后面继续。

#### 关键语法
- `while True:` 表示无限循环，通常配合 `return` 在合适位置退出。
- 这题的难点不是语法，而是指针关系。

## 11. #138 随机链表的复制

### 题目描述
给你一个特殊链表，每个节点除了 `next` 指针外，还有一个 `random` 指针，`random` 可以指向链表中的任意节点，也可以是 `None`。

请你深拷贝这个链表，并返回复制后的头节点。要求新链表中的节点全部是新创建的，不能与原链表共享节点。

### 示例

**示例 1：**

```text
输入:
7 -> 13 -> 11 -> 10 -> 1
random 指向关系:
7.random = None
13.random = 7
11.random = 1
10.random = 11
1.random = 7

输出:
复制后的链表结构和 random 指向关系完全一致
```

### Python 解法

```python
class Solution:
    def copyRandomList(self, head: 'Node') -> 'Node':
        if not head:
            return None

        old_to_new = {}

        cur = head
        while cur:
            old_to_new[cur] = Node(cur.val)
            cur = cur.next

        cur = head
        while cur:
            old_to_new[cur].next = old_to_new.get(cur.next)
            old_to_new[cur].random = old_to_new.get(cur.random)
            cur = cur.next

        return old_to_new[head]
```

### 代码详细解析

#### 思路分析
使用哈希表建立“旧节点 -> 新节点”的映射。

分两遍遍历：
1. 第一遍：只复制所有节点值，创建新节点。
2. 第二遍：根据映射补上每个新节点的 `next` 和 `random`。

#### 逐行解析
- `if not head:`：如果原链表为空，直接返回空。
- `old_to_new = {}`：哈希表，键是旧节点，值是对应的新节点。
- 第一轮循环：
  - `old_to_new[cur] = Node(cur.val)`：为每个旧节点创建一个新节点，但暂时不连边。
- 第二轮循环：
  - `old_to_new[cur].next = old_to_new.get(cur.next)`：
    - 找到旧节点 `cur` 对应的新节点；
    - 把它的 `next` 指向“旧节点下一个节点所对应的新节点”。
  - `old_to_new[cur].random = old_to_new.get(cur.random)`：同理设置 `random`。
- `return old_to_new[head]`：返回原头节点对应的新头节点。

#### 关键语法
- 字典可以用对象做键。
- `dict.get(key)`：
  - 如果键存在，返回对应值；
  - 如果不存在，返回 `None`。
  - 这里非常适合处理 `cur.next` 或 `cur.random` 为空的情况。

## 12. #148 排序链表

### 题目描述
给你一个链表的头节点 `head`，请将其按升序排序，并返回排序后的链表头节点。

### 示例

**示例 1：**

```text
输入: 4 -> 2 -> 1 -> 3
输出: 1 -> 2 -> 3 -> 4
```

**示例 2：**

```text
输入: -1 -> 5 -> 3 -> 4 -> 0
输出: -1 -> 0 -> 3 -> 4 -> 5
```

### Python 解法

```python
class Solution:
    def sortList(self, head: ListNode) -> ListNode:
        if not head or not head.next:
            return head

        slow, fast = head, head.next
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        mid = slow.next
        slow.next = None

        left = self.sortList(head)
        right = self.sortList(mid)

        dummy = ListNode(0)
        cur = dummy

        while left and right:
            if left.val < right.val:
                cur.next = left
                left = left.next
            else:
                cur.next = right
                right = right.next
            cur = cur.next

        cur.next = left if left else right
        return dummy.next
```

### 代码详细解析

#### 思路分析
链表排序最常见的做法是“归并排序”。

归并排序适合链表的原因：
- 找中点方便；
- 合并两个有序链表也很方便；
- 时间复杂度可以做到 `O(n log n)`。

整体分三步：
1. 找中点并切开。
2. 递归排序左半部分和右半部分。
3. 合并两个有序链表。

#### 逐行解析
- `if not head or not head.next:`：
  - 如果链表为空或只有一个节点，本身就有序，直接返回。
- `slow, fast = head, head.next`：快慢指针找中点。
- `mid = slow.next`：中间断开点。
- `slow.next = None`：把链表切成两半。
- `left = self.sortList(head)`：递归排序左半部分。
- `right = self.sortList(mid)`：递归排序右半部分。

合并部分：
- `dummy = ListNode(0)`：虚拟头结点。
- `while left and right:`：比较两个有序链表当前节点。
- `if left.val < right.val:`：取较小值接到结果链表。
- `cur.next = left if left else right`：把剩余部分整体接上。
- `return dummy.next`：返回排序后链表头。

#### 关键语法
- 递归函数里调用自己：`self.sortList(...)`。
- 归并排序的核心不在语法，而在“分 + 治 + 合并”。

## 13. #23 合并 K 个升序链表

### 题目描述
给你一个链表数组 `lists`，其中每个链表都已经按升序排列。请你将所有链表合并为一个升序链表，并返回合并后的头节点。

### 示例

**示例 1：**

```text
输入: lists = [
  1 -> 4 -> 5,
  1 -> 3 -> 4,
  2 -> 6
]
输出: 1 -> 1 -> 2 -> 3 -> 4 -> 4 -> 5 -> 6
```

**示例 2：**

```text
输入: lists = []
输出: []
```

**示例 3：**

```text
输入: lists = [[]]
输出: []
```

### Python 解法

```python
class Solution:
    def mergeKLists(self, lists: List[ListNode]) -> ListNode:
        if not lists:
            return None

        while len(lists) > 1:
            merged_lists = []
            for i in range(0, len(lists), 2):
                l1 = lists[i]
                l2 = lists[i + 1] if i + 1 < len(lists) else None
                merged_lists.append(self.mergeTwoLists(l1, l2))
            lists = merged_lists

        return lists[0]

    def mergeTwoLists(self, l1, l2):
        dummy = ListNode(0)
        cur = dummy

        while l1 and l2:
            if l1.val < l2.val:
                cur.next = l1
                l1 = l1.next
            else:
                cur.next = l2
                l2 = l2.next
            cur = cur.next

        cur.next = l1 if l1 else l2
        return dummy.next
```

### 代码详细解析

#### 思路分析
这道题的经典做法之一是“分治合并”。

不要一次性把 K 个链表全部硬合并，而是：
- 先两两合并；
- 再把合并结果继续两两合并；
- 最终只剩一个链表。

这和归并排序的思想很像。

#### 逐行解析
- `if not lists:`：如果数组为空，直接返回 `None`。
- `while len(lists) > 1:`：只要还不止一个链表，就继续合并。
- `merged_lists = []`：存放本轮两两合并后的结果。
- `for i in range(0, len(lists), 2):`：
  - 从 0 开始，每次步长为 2；
  - 也就是每次取两个链表出来合并。
- `l2 = lists[i + 1] if i + 1 < len(lists) else None`：
  - 如果最后剩下单独一个链表，就和 `None` 合并。
- `merged_lists.append(self.mergeTwoLists(l1, l2))`：把合并结果加入新数组。
- `lists = merged_lists`：更新链表数组，进入下一轮。
- `return lists[0]`：最后只剩一个链表时返回。

`mergeTwoLists` 方法和第 21 题几乎一样，就是合并两个有序链表。

#### 关键语法
- `range(0, len(lists), 2)`：从 0 到末尾，每次跨 2 步。
- 分治法可以降低整体复杂度，是这题面试中的主流解法。

## 14. #146 LRU 缓存

### 题目描述
请你设计并实现一个满足 LRU（Least Recently Used，最近最少使用）规则的缓存结构。

实现 `LRUCache` 类：
- `LRUCache(capacity)`：用正整数 `capacity` 初始化缓存容量。
- `get(key)`：如果 `key` 存在，返回其值；否则返回 `-1`。读取后，该键会变成“最近使用”。
- `put(key, value)`：插入或修改键值对。如果插入后超出容量，需要删除“最久未使用”的键。

要求 `get` 和 `put` 平均时间复杂度尽量为 `O(1)`。

### 示例

**示例 1：**

```text
输入:
LRUCache(2)
put(1, 1)
put(2, 2)
get(1)      -> 1
put(3, 3)   -> 淘汰 key 2
get(2)      -> -1
put(4, 4)   -> 淘汰 key 1
get(1)      -> -1
get(3)      -> 3
get(4)      -> 4
```

### Python 解法

```python
class Node:
    def __init__(self, key=0, value=0):
        self.key = key
        self.value = value
        self.prev = None
        self.next = None


class LRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.cache = {}

        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head

    def _remove(self, node):
        prev = node.prev
        nxt = node.next
        prev.next = nxt
        nxt.prev = prev

    def _add_to_front(self, node):
        node.prev = self.head
        node.next = self.head.next
        self.head.next.prev = node
        self.head.next = node

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1

        node = self.cache[key]
        self._remove(node)
        self._add_to_front(node)
        return node.value

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            node = self.cache[key]
            node.value = value
            self._remove(node)
            self._add_to_front(node)
        else:
            node = Node(key, value)
            self.cache[key] = node
            self._add_to_front(node)

            if len(self.cache) > self.capacity:
                lru = self.tail.prev
                self._remove(lru)
                del self.cache[lru.key]
```

### 代码详细解析

#### 思路分析
这道题是“哈希表 + 双向链表”的经典组合。

为什么要这样设计？
- 哈希表：实现 `key -> 节点` 的快速查找，时间复杂度 `O(1)`。
- 双向链表：实现节点的快速删除和插入，时间复杂度 `O(1)`。

双向链表中的顺序表示“最近使用顺序”：
- 头部附近：最近刚使用过
- 尾部附近：最久没使用

#### 结构设计
- `cache`：字典，存储 `key: node`
- `head` 和 `tail`：两个哨兵节点，方便头插和尾删

#### 逐行解析

**Node 类：**
- `key` 和 `value`：保存键值对。
- `prev`、`next`：双向链表指针。

**初始化：**
- `self.capacity = capacity`：缓存容量。
- `self.cache = {}`：哈希表。
- 创建 `head`、`tail` 两个哨兵节点。
- `self.head.next = self.tail`、`self.tail.prev = self.head`：初始化为空链表。

**辅助函数 `_remove(node)`：**
- 删除某个节点。
- `prev.next = nxt`、`nxt.prev = prev`：跳过该节点。

**辅助函数 `_add_to_front(node)`：**
- 把某个节点插到链表头部。
- 因为头部表示最近使用，所以每次访问或插入都放头部。

**`get(key)`：**
- 如果 `key` 不存在，返回 `-1`。
- 如果存在：
  1. 找到对应节点；
  2. 从原位置删除；
  3. 插到链表头部；
  4. 返回它的值。

**`put(key, value)`：**
- 如果键已存在：
  - 更新值；
  - 把该节点移动到头部。
- 如果键不存在：
  - 新建节点；
  - 加入字典；
  - 插入头部。
- 如果容量超了：
  - `self.tail.prev` 就是最久未使用节点；
  - 删除它；
  - 同时从字典里删掉。

#### 关键语法
- `if key not in self.cache:`：判断字典中是否存在某键。
- `del self.cache[lru.key]`：删除字典中的某个键。
- 双向链表删除节点时，知道节点本身即可 `O(1)` 删除，这是这题的关键。

# 总结：链表题常见套路

学习完这部分后，你要重点掌握下面几种核心套路：

1. **虚拟头结点 dummy**
   - 解决头节点修改问题。
   - 常用于删除、合并、交换节点等题。

2. **快慢指针**
   - 找中点：#234、#148
   - 判断是否有环：#141
   - 找环入口：#142
   - 删除倒数第 N 个节点：#19

3. **链表反转**
   - 基础题：#206
   - 进阶应用：#234、#25

4. **哈希表辅助**
   - 节点映射：#138
   - LRU：#146
   - 判重或记录访问：某些环问题也可以这样做，但不是最优。

5. **分治 / 归并排序**
   - 排序链表：#148
   - 合并 K 个有序链表：#23

6. **双向链表设计题**
   - LRU 缓存是链表设计题中的代表。
