## 1. #215 数组中的第 K 个最大元素

### 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你返回数组中第 `k` 个最大的元素。

注意：题目要求的是排序后第 `k` 个最大的元素，不是第 `k` 个不同的元素。

### 示例

**示例 1：**

```text
输入: nums = [3,2,1,5,6,4], k = 2
输出: 5
解释: 数组从大到小排序为 [6,5,4,3,2,1]，第 2 大是 5。
```

**示例 2：**

```text
输入: nums = [3,2,3,1,2,4,5,5,6], k = 4
输出: 4
解释: 排序后为 [6,5,5,4,3,3,2,2,1]，第 4 大是 4。
```

### Python 解法：小顶堆

```python
from typing import List
import heapq

class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        heap = []

        for num in nums:
            heapq.heappush(heap, num)

            if len(heap) > k:
                heapq.heappop(heap)

        return heap[0]
```

### 代码详细解析

#### 核心思路

这道题可以直接排序：

```python
nums.sort(reverse=True)
return nums[k - 1]
```

但更常见的面试写法是使用 **大小为 k 的小顶堆**。

小顶堆的特点是：

```text
堆顶永远是当前堆中最小的元素
```

我们维护一个只保存 `k` 个元素的小顶堆。遍历数组时：

1. 把当前数字放进堆；
2. 如果堆的大小超过 `k`，就弹出堆顶最小值；
3. 最后堆中留下的就是数组中最大的 `k` 个元素；
4. 这 `k` 个元素里最小的那个，也就是第 `k` 大元素，位于堆顶。

#### 逐行解析

```python
heap = []
```

创建一个空列表，用来作为堆。

Python 的 `heapq` 默认实现的是小顶堆。

```python
for num in nums:
```

遍历数组中的每一个数字。

```python
heapq.heappush(heap, num)
```

把当前数字压入堆中，并自动维持小顶堆结构。

```python
if len(heap) > k:
    heapq.heappop(heap)
```

如果堆中元素数量超过 `k`，就弹出最小的那个。  
这样堆中始终只保留当前见过的最大的 `k` 个数。

```python
return heap[0]
```

循环结束后，堆中保存的是最大的 `k` 个数。  
堆顶 `heap[0]` 是这 `k` 个数中最小的，也就是整个数组第 `k` 大的元素。

#### 关键语法

- `import heapq`：导入 Python 内置堆模块。
- `heapq.heappush(heap, num)`：把元素加入堆。
- `heapq.heappop(heap)`：弹出堆顶最小元素。
- `heap[0]`：访问堆顶元素。
- `len(heap)`：获取堆中元素数量。

#### 复杂度分析

- 时间复杂度：`O(n log k)`，每个元素最多入堆一次，堆大小最多为 `k`。
- 空间复杂度：`O(k)`，堆中最多保存 `k` 个元素。

## 2. #347 前 K 个高频元素

### 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你返回出现频率最高的 `k` 个元素。

答案可以按任意顺序返回。

### 示例

**示例 1：**

```text
输入: nums = [1,1,1,2,2,3], k = 2
输出: [1,2]
解释: 1 出现 3 次，2 出现 2 次，3 出现 1 次，频率最高的两个元素是 1 和 2。
```

**示例 2：**

```text
输入: nums = [1], k = 1
输出: [1]
```

### Python 解法：哈希表 + 小顶堆

```python
from typing import List
from collections import Counter
import heapq

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        count = Counter(nums)
        heap = []

        for num, freq in count.items():
            heapq.heappush(heap, (freq, num))

            if len(heap) > k:
                heapq.heappop(heap)

        return [num for freq, num in heap]
```

### 代码详细解析

#### 核心思路

这道题分两步：

1. 统计每个数字出现的次数；
2. 找出频率最高的 `k` 个数字。

统计频率可以用哈希表。  
找前 `k` 大频率可以用大小为 `k` 的小顶堆。

堆中保存：

```python
(freq, num)
```

表示数字 `num` 出现了 `freq` 次。

维护一个大小为 `k` 的小顶堆，堆顶是当前前 `k` 高频元素中频率最低的那个。  
如果堆大小超过 `k`，就弹出频率最低的元素。

#### 逐行解析

```python
count = Counter(nums)
```

`Counter` 会统计每个元素出现的次数。

例如：

```python
nums = [1,1,1,2,2,3]
```

得到：

```python
Counter({1: 3, 2: 2, 3: 1})
```

```python
heap = []
```

创建小顶堆。

```python
for num, freq in count.items():
```

遍历每个数字及其频率。

- `num` 是数字；
- `freq` 是出现次数。

```python
heapq.heappush(heap, (freq, num))
```

把 `(频率, 数字)` 放入堆中。  
Python 比较元组时，会先比较第一个元素，所以这里堆会按照 `freq` 排序。

```python
if len(heap) > k:
    heapq.heappop(heap)
```

如果堆中超过 `k` 个元素，就弹出频率最低的那个。

```python
return [num for freq, num in heap]
```

返回堆中所有数字。  
题目允许任意顺序，所以不需要再排序。

#### 关键语法

- `Counter(nums)`：快速统计元素频率。
- `count.items()`：返回 `(键, 值)` 对。
- `(freq, num)`：元组，堆会优先按照 `freq` 排序。
- 列表推导式：`[num for freq, num in heap]`。

#### 复杂度分析

设数组长度为 `n`，不同元素个数为 `m`：

- 时间复杂度：`O(n + m log k)`。
- 空间复杂度：`O(m + k)`，哈希表需要 `m`，堆需要 `k`。

## 3. #295 数据流的中位数

### 题目描述

中位数是有序列表中间的数。

- 如果列表长度是奇数，中位数是最中间的数；
- 如果列表长度是偶数，中位数是中间两个数的平均值。

请你设计一个数据结构，支持：

- `addNum(num)`：从数据流中添加一个整数；
- `findMedian()`：返回目前所有元素的中位数。

### 示例

```text
输入:
MedianFinder medianFinder = new MedianFinder()
medianFinder.addNum(1)
medianFinder.addNum(2)
medianFinder.findMedian() -> 1.5
medianFinder.addNum(3)
medianFinder.findMedian() -> 2.0
```

### Python 解法：双堆

```python
import heapq

class MedianFinder:

    def __init__(self):
        self.small = []
        self.large = []

    def addNum(self, num: int) -> None:
        heapq.heappush(self.small, -num)

        if self.small and self.large and -self.small[0] > self.large[0]:
            val = -heapq.heappop(self.small)
            heapq.heappush(self.large, val)

        if len(self.small) > len(self.large) + 1:
            val = -heapq.heappop(self.small)
            heapq.heappush(self.large, val)

        if len(self.large) > len(self.small):
            val = heapq.heappop(self.large)
            heapq.heappush(self.small, -val)

    def findMedian(self) -> float:
        if len(self.small) > len(self.large):
            return float(-self.small[0])

        return (-self.small[0] + self.large[0]) / 2
```

### 代码详细解析

#### 核心思路

为了动态维护中位数，常见做法是使用两个堆：

1. `small`：保存较小的一半数字，使用大顶堆；
2. `large`：保存较大的一半数字，使用小顶堆。

Python 没有直接的大顶堆，所以用负数模拟：

```python
heapq.heappush(self.small, -num)
```

实际值越大，负数越小，就会排在小顶堆堆顶，从而模拟大顶堆。

需要维护两个条件：

1. `small` 中的所有元素都要小于等于 `large` 中的所有元素；
2. `small` 的长度要么等于 `large`，要么比 `large` 多 1。

这样：

- 如果总数是奇数，中位数就是 `small` 的堆顶；
- 如果总数是偶数，中位数就是两个堆顶的平均值。

#### 逐行解析

```python
self.small = []
self.large = []
```

初始化两个堆。

- `small` 存较小的一半，用负数模拟大顶堆；
- `large` 存较大的一半，是正常小顶堆。

```python
heapq.heappush(self.small, -num)
```

先把新数字加入 `small`。  
注意加入的是 `-num`。

```python
if self.small and self.large and -self.small[0] > self.large[0]:
```

检查两个堆是否顺序错误。

- `-self.small[0]` 是较小一半里的最大值；
- `self.large[0]` 是较大一半里的最小值。

如果较小一半的最大值反而大于较大一半的最小值，说明需要调整。

```python
val = -heapq.heappop(self.small)
heapq.heappush(self.large, val)
```

把 `small` 中最大的实际值移动到 `large`。

```python
if len(self.small) > len(self.large) + 1:
```

如果 `small` 比 `large` 多超过一个元素，需要把一个元素移过去。

```python
val = -heapq.heappop(self.small)
heapq.heappush(self.large, val)
```

把 `small` 的最大值移动到 `large`。

```python
if len(self.large) > len(self.small):
```

如果 `large` 比 `small` 长，为了让 `small` 保存中间偏左的元素，需要移动一个元素到 `small`。

```python
val = heapq.heappop(self.large)
heapq.heappush(self.small, -val)
```

从 `large` 中取最小值，加入 `small`。

```python
if len(self.small) > len(self.large):
    return float(-self.small[0])
```

如果总数量是奇数，`small` 多一个元素，中位数就是 `small` 堆顶对应的实际值。

```python
return (-self.small[0] + self.large[0]) / 2
```

如果总数量是偶数，中位数是两个堆顶的平均值。

#### 关键语法

- `heapq` 默认是小顶堆。
- 用负数可以模拟大顶堆。
- `self.small[0]` 是堆顶元素。
- `float(x)` 把整数转成浮点数。

#### 复杂度分析

- `addNum` 时间复杂度：`O(log n)`。
- `findMedian` 时间复杂度：`O(1)`。
- 空间复杂度：`O(n)`。

## 1. #121 买卖股票的最佳时机

### 题目描述

给你一个数组 `prices`，其中 `prices[i]` 表示某只股票第 `i` 天的价格。

你只能选择某一天买入股票，并选择未来某一天卖出股票。请你计算能够获得的最大利润。

如果无法获得利润，返回 `0`。

### 示例

**示例 1：**

```text
输入: prices = [7,1,5,3,6,4]
输出: 5
解释: 第 2 天价格为 1 时买入，第 5 天价格为 6 时卖出，利润为 5。
```

**示例 2：**

```text
输入: prices = [7,6,4,3,1]
输出: 0
解释: 价格一直下降，无法获利。
```

### Python 解法

```python
from typing import List

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        min_price = float("inf")
        max_profit = 0

        for price in prices:
            if price < min_price:
                min_price = price

            profit = price - min_price
            if profit > max_profit:
                max_profit = profit

        return max_profit
```

### 代码详细解析

#### 核心思路

这道题的贪心点是：

```text
如果今天卖出，那么最好的买入价格一定是今天之前出现过的最低价。
```

所以遍历每一天价格时，维护两个变量：

- `min_price`：到目前为止见过的最低价格；
- `max_profit`：到目前为止能获得的最大利润。

每一天都假设在当天卖出，计算：

```python
profit = price - min_price
```

然后更新最大利润。

#### 逐行解析

```python
min_price = float("inf")
```

初始化最低价格为正无穷，保证第一天价格一定能更新它。

```python
max_profit = 0
```

最大利润初始为 0。  
如果价格一直下降，就不交易，利润仍然为 0。

```python
for price in prices:
```

遍历每天的股票价格。

```python
if price < min_price:
    min_price = price
```

如果当前价格比历史最低价还低，就更新最低价。

```python
profit = price - min_price
```

假设今天卖出，计算利润。

```python
if profit > max_profit:
    max_profit = profit
```

如果当前利润更大，就更新最大利润。

```python
return max_profit
```

返回最大利润。

#### 关键语法

- `float("inf")`：正无穷大。
- `for price in prices:`：遍历列表元素。
- 贪心思想：每一步都保存当前最优的买入价格。

#### 复杂度分析

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

## 2. #55 跳跃游戏

### 题目描述

给你一个非负整数数组 `nums`，你最初位于数组的第一个下标。

数组中的每个元素表示你在该位置最多可以跳跃的长度。

请判断你是否能够到达最后一个下标。

### 示例

**示例 1：**

```text
输入: nums = [2,3,1,1,4]
输出: True
解释: 先从下标 0 跳到下标 1，再从下标 1 跳到最后一个位置。
```

**示例 2：**

```text
输入: nums = [3,2,1,0,4]
输出: False
解释: 最远只能到达下标 3，而下标 3 的跳跃长度为 0，无法继续前进。
```

### Python 解法

```python
from typing import List

class Solution:
    def canJump(self, nums: List[int]) -> bool:
        farthest = 0

        for i, jump in enumerate(nums):
            if i > farthest:
                return False

            farthest = max(farthest, i + jump)

            if farthest >= len(nums) - 1:
                return True

        return True
```

### 代码详细解析

#### 核心思路

这道题的贪心点是：

```text
维护当前能够到达的最远位置 farthest。
```

遍历每个位置时：

- 如果当前位置 `i` 大于 `farthest`，说明当前位置根本到不了，返回 `False`；
- 否则可以从当前位置继续跳，尝试更新最远可达位置；
- 如果 `farthest` 已经到达或超过最后一个下标，返回 `True`。

#### 逐行解析

```python
farthest = 0
```

初始时只能站在下标 0，所以最远可达位置是 0。

```python
for i, jump in enumerate(nums):
```

遍历数组，`i` 是当前下标，`jump` 是当前位置最多能跳多远。

```python
if i > farthest:
    return False
```

如果当前下标已经超过目前最远可达位置，说明无法走到这里，也无法继续前进。

```python
farthest = max(farthest, i + jump)
```

从当前位置最多可以跳到 `i + jump`。  
用它更新当前最远可达位置。

```python
if farthest >= len(nums) - 1:
    return True
```

如果已经能到达最后一个位置，直接返回 `True`。

```python
return True
```

如果循环正常结束，说明一路可达。

#### 关键语法

- `enumerate(nums)`：同时获取下标和值。
- `max(a, b)`：返回较大值。
- `len(nums) - 1`：最后一个下标。

#### 复杂度分析

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

## 3. #45 跳跃游戏 II

### 题目描述

给你一个非负整数数组 `nums`，你最初位于数组的第一个位置。

数组中的每个元素表示你在该位置最多可以跳跃的长度。

请你返回到达最后一个位置所需的最少跳跃次数。

题目保证一定可以到达最后一个位置。

### 示例

**示例 1：**

```text
输入: nums = [2,3,1,1,4]
输出: 2
解释: 从下标 0 跳到下标 1，再跳到最后一个位置。
```

**示例 2：**

```text
输入: nums = [2,3,0,1,4]
输出: 2
```

### Python 解法

```python
from typing import List

class Solution:
    def jump(self, nums: List[int]) -> int:
        jumps = 0
        current_end = 0
        farthest = 0

        for i in range(len(nums) - 1):
            farthest = max(farthest, i + nums[i])

            if i == current_end:
                jumps += 1
                current_end = farthest

        return jumps
```

### 代码详细解析

#### 核心思路

这道题可以理解为 BFS 的层次扩展，也可以用贪心写成一维扫描。

变量含义：

- `current_end`：当前这一步能覆盖的最远边界；
- `farthest`：在当前这一步范围内，下一步能到达的最远位置；
- `jumps`：已经跳了多少次。

当遍历到 `current_end` 时，说明当前这一跳的覆盖范围已经走完，必须再跳一次，于是：

```python
jumps += 1
current_end = farthest
```

#### 逐行解析

```python
jumps = 0
current_end = 0
farthest = 0
```

- `jumps` 初始跳跃次数为 0；
- `current_end` 当前跳跃覆盖范围的右边界；
- `farthest` 下一次跳跃可覆盖的最远位置。

```python
for i in range(len(nums) - 1):
```

只遍历到倒数第二个位置。  
因为到达最后一个位置后不需要再跳。

```python
farthest = max(farthest, i + nums[i])
```

更新从当前范围内任意位置出发，下一跳能到达的最远位置。

```python
if i == current_end:
```

如果已经走到当前跳跃范围的边界，说明必须增加一次跳跃。

```python
jumps += 1
current_end = farthest
```

跳跃次数加一，并把当前覆盖边界扩展到 `farthest`。

```python
return jumps
```

返回最少跳跃次数。

#### 关键语法

- `range(len(nums) - 1)`：不遍历最后一个位置。
- 这题的关键不是每次真的“跳到哪个点”，而是维护“当前跳数能覆盖的范围”。

#### 复杂度分析

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

## 4. #763 划分字母区间

### 题目描述

给你一个字符串 `s`，请你把字符串划分为尽可能多的片段，使得每个字母最多出现在一个片段中。

返回每个片段的长度。

### 示例

**示例 1：**

```text
输入: s = "ababcbacadefegdehijhklij"
输出: [9,7,8]
解释:
划分结果为 "ababcbaca"、"defegde"、"hijhklij"。
每个字母最多只出现在一个片段中。
```

**示例 2：**

```text
输入: s = "eccbbbbdec"
输出: [10]
解释: 所有字符必须放在同一个片段中。
```

### Python 解法

```python
from typing import List

class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        last = {}

        for i, ch in enumerate(s):
            last[ch] = i

        res = []
        start = 0
        end = 0

        for i, ch in enumerate(s):
            end = max(end, last[ch])

            if i == end:
                res.append(end - start + 1)
                start = i + 1

        return res
```

### 代码详细解析

#### 核心思路

这道题的贪心点是：

```text
一个片段中只要包含某个字符，就必须覆盖这个字符最后一次出现的位置。
```

所以先统计每个字符最后出现的位置。  
然后从左到右遍历字符串，维护当前片段必须到达的最远右边界 `end`。

当遍历位置 `i == end` 时，说明当前片段中所有字符的最后一次出现位置都已经被覆盖，此时可以切一刀。

#### 逐行解析

```python
last = {}
```

创建字典，用来保存每个字符最后一次出现的位置。

```python
for i, ch in enumerate(s):
    last[ch] = i
```

遍历字符串。  
如果一个字符多次出现，后面的下标会覆盖前面的下标，所以最终保存的是最后一次出现的位置。

```python
res = []
start = 0
end = 0
```

- `res` 保存每个片段长度；
- `start` 当前片段起点；
- `end` 当前片段必须覆盖到的最远位置。

```python
for i, ch in enumerate(s):
```

再次遍历字符串。

```python
end = max(end, last[ch])
```

当前字符最后出现的位置是 `last[ch]`。  
当前片段必须至少覆盖到这个位置，所以更新右边界。

```python
if i == end:
```

如果当前位置已经到达当前片段的最远边界，说明可以切分。

```python
res.append(end - start + 1)
```

当前片段长度是：

```text
end - start + 1
```

```python
start = i + 1
```

下一个片段从 `i + 1` 开始。

```python
return res
```

返回所有片段长度。

#### 关键语法

- `last[ch] = i`：字典记录字符最后位置。
- `enumerate(s)`：遍历字符串时同时拿到下标和字符。
- `end - start + 1`：闭区间长度公式。

#### 复杂度分析

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`，因为小写字母最多 26 个。

## 1. #70 爬楼梯

### 题目描述

假设你正在爬楼梯，需要爬到第 `n` 阶。

每次你可以爬 `1` 阶或者 `2` 阶。请问爬到第 `n` 阶一共有多少种不同的方法？

### 示例

**示例 1：**

```text
输入: n = 2
输出: 2
解释:
1. 1 阶 + 1 阶
2. 2 阶
```

**示例 2：**

```text
输入: n = 3
输出: 3
解释:
1. 1 + 1 + 1
2. 1 + 2
3. 2 + 1
```

### Python 解法

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        if n <= 2:
            return n

        prev2 = 1
        prev1 = 2

        for i in range(3, n + 1):
            cur = prev1 + prev2
            prev2 = prev1
            prev1 = cur

        return prev1
```

### 代码详细解析

#### 核心思路

要到达第 `n` 阶，最后一步只有两种可能：

1. 从第 `n - 1` 阶爬 1 阶上来；
2. 从第 `n - 2` 阶爬 2 阶上来。

所以状态转移方程是：

```text
dp[n] = dp[n - 1] + dp[n - 2]
```

这其实就是斐波那契数列。

#### 逐行解析

```python
if n <= 2:
    return n
```

当 `n = 1` 时，只有 1 种方法。  
当 `n = 2` 时，有 2 种方法。

```python
prev2 = 1
prev1 = 2
```

用两个变量代替数组：

- `prev2` 表示 `dp[i - 2]`；
- `prev1` 表示 `dp[i - 1]`。

```python
for i in range(3, n + 1):
```

从第 3 阶开始计算，一直到第 `n` 阶。

```python
cur = prev1 + prev2
```

当前阶方法数等于前两阶方法数之和。

```python
prev2 = prev1
prev1 = cur
```

向后滚动更新变量。

```python
return prev1
```

返回第 `n` 阶的方法数。

#### 关键语法

- `range(3, n + 1)`：包含 3，不包含 `n + 1`，所以实际到 `n`。
- 滚动变量可以把空间复杂度从 `O(n)` 降到 `O(1)`。

#### 复杂度分析

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

## 2. #118 杨辉三角

### 题目描述

给你一个整数 `numRows`，请你生成杨辉三角的前 `numRows` 行。

杨辉三角中：

- 每行的第一个和最后一个数字都是 `1`；
- 中间每个数字等于上一行相邻两个数字之和。

### 示例

**示例 1：**

```text
输入: numRows = 5
输出:
[
     [1],
    [1,1],
   [1,2,1],
  [1,3,3,1],
 [1,4,6,4,1]
]
```

**示例 2：**

```text
输入: numRows = 1
输出: [[1]]
```

### Python 解法

```python
from typing import List

class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        res = []

        for i in range(numRows):
            row = [1] * (i + 1)

            for j in range(1, i):
                row[j] = res[i - 1][j - 1] + res[i - 1][j]

            res.append(row)

        return res
```

### 代码详细解析

#### 核心思路

杨辉三角是一种非常直观的动态规划。

第 `i` 行第 `j` 个数满足：

```text
row[j] = 上一行[j - 1] + 上一行[j]
```

边界位置都是 `1`。

#### 逐行解析

```python
res = []
```

保存最终所有行。

```python
for i in range(numRows):
```

依次生成第 `0` 行到第 `numRows - 1` 行。

```python
row = [1] * (i + 1)
```

创建当前行，长度是 `i + 1`，并且先全部填成 `1`。

例如第 3 行长度为 4：

```python
[1, 1, 1, 1]
```

```python
for j in range(1, i):
```

只计算中间位置。

- 第一个位置下标 0 不需要改；
- 最后一个位置下标 i 不需要改；
- 所以 `j` 从 1 到 `i - 1`。

```python
row[j] = res[i - 1][j - 1] + res[i - 1][j]
```

当前数字等于上一行左上方和右上方数字之和。

```python
res.append(row)
```

把当前行加入结果。

```python
return res
```

返回整个杨辉三角。

#### 关键语法

- `[1] * (i + 1)`：创建全是 1 的列表。
- `res[i - 1][j - 1]`：访问上一行左上角。
- `res[i - 1][j]`：访问上一行右上角。

#### 复杂度分析

- 时间复杂度：`O(numRows^2)`。
- 空间复杂度：`O(numRows^2)`，用于存储结果。

## 3. #198 打家劫舍

### 题目描述

你是一个小偷，计划偷窃沿街的房屋。每间房子里都有一定金额的钱。

但是相邻的两间房屋装有联动报警系统，如果同一晚上偷窃相邻的两间房，就会触发报警。

给你一个整数数组 `nums`，其中 `nums[i]` 表示第 `i` 间房屋的钱数。请你返回在不触发报警的情况下，最多能偷到多少钱。

### 示例

**示例 1：**

```text
输入: nums = [1,2,3,1]
输出: 4
解释: 偷第 1 间和第 3 间，金额为 1 + 3 = 4。
```

**示例 2：**

```text
输入: nums = [2,7,9,3,1]
输出: 12
解释: 偷第 1、3、5 间，金额为 2 + 9 + 1 = 12。
```

### Python 解法

```python
from typing import List

class Solution:
    def rob(self, nums: List[int]) -> int:
        prev2 = 0
        prev1 = 0

        for money in nums:
            cur = max(prev1, prev2 + money)
            prev2 = prev1
            prev1 = cur

        return prev1
```

### 代码详细解析

#### 核心思路

对每一间房，有两个选择：

1. 不偷当前房子：最大收益就是前一间房为止的最大收益；
2. 偷当前房子：前一间不能偷，只能加上前两间为止的最大收益。

状态转移：

```text
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
```

#### 逐行解析

```python
prev2 = 0
prev1 = 0
```

使用两个变量滚动表示：

- `prev2`：前两间房为止的最大收益；
- `prev1`：前一间房为止的最大收益。

```python
for money in nums:
```

遍历每间房的钱数。

```python
cur = max(prev1, prev2 + money)
```

当前最大收益有两种选择：

- 不偷当前房：`prev1`
- 偷当前房：`prev2 + money`

取较大值。

```python
prev2 = prev1
prev1 = cur
```

滚动更新状态。

```python
return prev1
```

返回最终最大收益。

#### 关键语法

- `max(a, b)`：取两个选择中的较大值。
- 动态规划中，是否可以压缩空间取决于当前状态只依赖几个前置状态。

#### 复杂度分析

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

## 4. #279 完全平方数

### 题目描述

给你一个整数 `n`，请你返回和为 `n` 的完全平方数的最少数量。

完全平方数指的是某个整数的平方，例如：

```text
1, 4, 9, 16, 25, ...
```

### 示例

**示例 1：**

```text
输入: n = 12
输出: 3
解释: 12 = 4 + 4 + 4。
```

**示例 2：**

```text
输入: n = 13
输出: 2
解释: 13 = 4 + 9。
```

### Python 解法

```python
class Solution:
    def numSquares(self, n: int) -> int:
        dp = [float("inf")] * (n + 1)
        dp[0] = 0

        squares = []
        i = 1
        while i * i <= n:
            squares.append(i * i)
            i += 1

        for i in range(1, n + 1):
            for square in squares:
                if square > i:
                    break
                dp[i] = min(dp[i], dp[i - square] + 1)

        return dp[n]
```

### 代码详细解析

#### 核心思路

这道题可以看成“完全背包”问题。

物品是：

```text
1, 4, 9, 16, ...
```

每个完全平方数可以重复使用。  
目标是凑出总和 `n`，并让使用数量最少。

定义：

```text
dp[i] = 凑出整数 i 所需的最少完全平方数数量
```

状态转移：

```text
dp[i] = min(dp[i], dp[i - square] + 1)
```

#### 逐行解析

```python
dp = [float("inf")] * (n + 1)
dp[0] = 0
```

`dp[i]` 初始设为无穷大，表示暂时不知道怎么凑。  
`dp[0] = 0` 表示凑出 0 不需要任何数。

```python
squares = []
i = 1
while i * i <= n:
    squares.append(i * i)
    i += 1
```

预先生成所有不超过 `n` 的完全平方数。

```python
for i in range(1, n + 1):
```

依次计算 `dp[1]` 到 `dp[n]`。

```python
for square in squares:
```

尝试使用每个完全平方数。

```python
if square > i:
    break
```

如果当前平方数已经大于 `i`，后面的平方数更大，不需要继续。

```python
dp[i] = min(dp[i], dp[i - square] + 1)
```

如果使用一个 `square`，那么剩下的问题就是凑出 `i - square`。  
所以候选答案是 `dp[i - square] + 1`。

```python
return dp[n]
```

返回凑出 `n` 的最少数量。

#### 关键语法

- `float("inf")`：表示正无穷大。
- `while i * i <= n`：生成平方数。
- `break`：提前结束循环，起到剪枝作用。

#### 复杂度分析

- 时间复杂度：`O(n * sqrt(n))`。
- 空间复杂度：`O(n)`。

## 5. #322 零钱兑换

### 题目描述

给你一个整数数组 `coins`，表示不同面额的硬币；再给你一个整数 `amount`，表示总金额。

请你计算可以凑成总金额所需的最少硬币数量。

如果无法凑出该金额，返回 `-1`。

每种硬币可以无限次使用。

### 示例

**示例 1：**

```text
输入: coins = [1,2,5], amount = 11
输出: 3
解释: 11 = 5 + 5 + 1。
```

**示例 2：**

```text
输入: coins = [2], amount = 3
输出: -1
解释: 不能用面额为 2 的硬币凑出 3。
```

**示例 3：**

```text
输入: coins = [1], amount = 0
输出: 0
```

### Python 解法

```python
from typing import List

class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        dp = [amount + 1] * (amount + 1)
        dp[0] = 0

        for coin in coins:
            for x in range(coin, amount + 1):
                dp[x] = min(dp[x], dp[x - coin] + 1)

        return dp[amount] if dp[amount] != amount + 1 else -1
```

### 代码详细解析

#### 核心思路

这道题也是完全背包问题：

- 每种硬币可以无限次使用；
- 目标是凑出 `amount`；
- 优化目标是使用硬币数量最少。

定义：

```text
dp[x] = 凑出金额 x 所需的最少硬币数
```

状态转移：

```text
dp[x] = min(dp[x], dp[x - coin] + 1)
```

#### 逐行解析

```python
dp = [amount + 1] * (amount + 1)
```

初始化数组。  
为什么用 `amount + 1` 表示无穷大？

因为最坏情况下，如果有面额为 1 的硬币，凑出 `amount` 最多需要 `amount` 枚硬币。  
所以 `amount + 1` 一定是一个不可能达到的较大值。

```python
dp[0] = 0
```

凑出金额 0 需要 0 枚硬币。

```python
for coin in coins:
```

遍历每一种硬币面额。

```python
for x in range(coin, amount + 1):
```

从 `coin` 开始计算，因为小于 `coin` 的金额不可能使用这个硬币。

这里正序遍历，是完全背包的典型写法，表示同一种硬币可以重复使用。

```python
dp[x] = min(dp[x], dp[x - coin] + 1)
```

如果使用一枚当前硬币 `coin`，那么剩下金额是 `x - coin`。  
所以候选数量是 `dp[x - coin] + 1`。

```python
return dp[amount] if dp[amount] != amount + 1 else -1
```

如果 `dp[amount]` 仍然是初始值，说明无法凑出，返回 `-1`。  
否则返回最少硬币数。

#### 关键语法

- `[amount + 1] * (amount + 1)`：创建长度为 `amount + 1` 的数组。
- `range(coin, amount + 1)`：从当前硬币面额开始遍历。
- `a if 条件 else b`：Python 三元表达式。

#### 复杂度分析

- 时间复杂度：`O(amount * len(coins))`。
- 空间复杂度：`O(amount)`。

## 6. #139 单词拆分

### 题目描述

给你一个字符串 `s` 和一个字符串列表 `wordDict`。

请你判断 `s` 是否可以被空格拆分成一个或多个在字典中出现的单词。

同一个字典中的单词可以被重复使用。

### 示例

**示例 1：**

```text
输入: s = "leetcode", wordDict = ["leet","code"]
输出: True
解释: "leetcode" 可以拆分为 "leet code"。
```

**示例 2：**

```text
输入: s = "applepenapple", wordDict = ["apple","pen"]
输出: True
解释: "applepenapple" 可以拆分为 "apple pen apple"。
```

**示例 3：**

```text
输入: s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]
输出: False
```

### Python 解法

```python
from typing import List

class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        word_set = set(wordDict)
        n = len(s)
        dp = [False] * (n + 1)
        dp[0] = True

        for i in range(1, n + 1):
            for j in range(i):
                if dp[j] and s[j:i] in word_set:
                    dp[i] = True
                    break

        return dp[n]
```

### 代码详细解析

#### 核心思路

定义状态：

```text
dp[i] = s 的前 i 个字符是否可以被成功拆分
```

也就是判断：

```python
s[0:i]
```

能不能拆成字典里的单词。

对于每个 `i`，枚举切分点 `j`：

```text
s[0:i] = s[0:j] + s[j:i]
```

如果：

1. `s[0:j]` 可以成功拆分，也就是 `dp[j] == True`；
2. `s[j:i]` 是字典中的单词；

那么 `dp[i] = True`。

#### 逐行解析

```python
word_set = set(wordDict)
```

把单词列表转成集合，加快查询速度。  
列表查询是 `O(n)`，集合查询平均是 `O(1)`。

```python
n = len(s)
dp = [False] * (n + 1)
dp[0] = True
```

`dp` 长度为 `n + 1`。  
`dp[0] = True` 表示空字符串可以被成功拆分。

```python
for i in range(1, n + 1):
```

依次判断前 `i` 个字符是否可以拆分。

```python
for j in range(i):
```

枚举切分点 `j`。

```python
if dp[j] and s[j:i] in word_set:
```

判断两个条件：

- `dp[j]`：前半部分能拆；
- `s[j:i] in word_set`：后半部分是字典单词。

```python
dp[i] = True
break
```

只要找到一种拆法，就可以确定 `dp[i] = True`，然后跳出内层循环。

```python
return dp[n]
```

判断整个字符串是否可以拆分。

#### 关键语法

- `set(wordDict)`：列表转集合。
- `s[j:i]`：字符串切片，表示从下标 `j` 到 `i - 1` 的子串。
- `break`：找到答案后提前结束循环。

#### 复杂度分析

- 时间复杂度：通常写作 `O(n^2)`，考虑切片成本时可能到 `O(n^3)`。
- 空间复杂度：`O(n)`。

## 7. #300 最长递增子序列

### 题目描述

给你一个整数数组 `nums`，请你找到其中最长严格递增子序列的长度。

子序列是指可以删除数组中的某些元素，剩下元素保持原来的相对顺序。

### 示例

**示例 1：**

```text
输入: nums = [10,9,2,5,3,7,101,18]
输出: 4
解释: 最长递增子序列可以是 [2,3,7,101]，长度为 4。
```

**示例 2：**

```text
输入: nums = [0,1,0,3,2,3]
输出: 4
```

**示例 3：**

```text
输入: nums = [7,7,7,7,7,7,7]
输出: 1
```

### Python 解法：动态规划

```python
from typing import List

class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [1] * n

        for i in range(n):
            for j in range(i):
                if nums[j] < nums[i]:
                    dp[i] = max(dp[i], dp[j] + 1)

        return max(dp)
```

### 代码详细解析

#### 核心思路

定义状态：

```text
dp[i] = 以 nums[i] 结尾的最长递增子序列长度
```

注意：必须以 `nums[i]` 结尾。

对于每个 `i`，向前找所有 `j < i`。  
如果：

```python
nums[j] < nums[i]
```

那么 `nums[i]` 可以接在以 `nums[j]` 结尾的递增子序列后面：

```text
dp[i] = max(dp[i], dp[j] + 1)
```

#### 逐行解析

```python
n = len(nums)
dp = [1] * n
```

每个元素单独都可以构成长度为 1 的递增子序列，所以初始值全是 1。

```python
for i in range(n):
```

遍历每个位置，计算以 `nums[i]` 结尾的最长递增子序列长度。

```python
for j in range(i):
```

枚举 `i` 前面的所有位置。

```python
if nums[j] < nums[i]:
```

只有当前面的数小于后面的数时，才可以构成严格递增。

```python
dp[i] = max(dp[i], dp[j] + 1)
```

尝试把 `nums[i]` 接到 `nums[j]` 后面。

```python
return max(dp)
```

最长递增子序列不一定以最后一个元素结尾，所以要返回 `dp` 数组中的最大值。

#### 关键语法

- `[1] * n`：初始化长度为 `n` 的数组。
- 双重循环适合初学者理解动态规划状态转移。
- `max(dp)`：获取数组中的最大值。

#### 复杂度分析

- 时间复杂度：`O(n^2)`。
- 空间复杂度：`O(n)`。

## 8. #152 乘积最大子数组

### 题目描述

给你一个整数数组 `nums`，请你找出数组中乘积最大的非空连续子数组，并返回这个最大乘积。

子数组必须是连续的。

### 示例

**示例 1：**

```text
输入: nums = [2,3,-2,4]
输出: 6
解释: 子数组 [2,3] 的乘积为 6。
```

**示例 2：**

```text
输入: nums = [-2,0,-1]
输出: 0
解释: 结果不能是 2，因为 [-2,-1] 不是连续子数组。
```

### Python 解法

```python
from typing import List

class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        max_prod = nums[0]
        min_prod = nums[0]
        ans = nums[0]

        for num in nums[1:]:
            if num < 0:
                max_prod, min_prod = min_prod, max_prod

            max_prod = max(num, max_prod * num)
            min_prod = min(num, min_prod * num)

            ans = max(ans, max_prod)

        return ans
```

### 代码详细解析

#### 核心思路

这道题比“最大子数组和”更复杂，因为乘法遇到负数会反转大小关系：

```text
一个很小的负数 × 一个负数 = 很大的正数
```

所以不能只维护最大乘积，还要同时维护最小乘积。

定义：

- `max_prod`：以当前位置结尾的最大乘积；
- `min_prod`：以当前位置结尾的最小乘积；
- `ans`：全局最大乘积。

当当前数字 `num` 是负数时，最大和最小会交换角色，所以先交换：

```python
max_prod, min_prod = min_prod, max_prod
```

#### 逐行解析

```python
max_prod = nums[0]
min_prod = nums[0]
ans = nums[0]
```

初始化为第一个元素。

```python
for num in nums[1:]:
```

从第二个元素开始遍历。

```python
if num < 0:
    max_prod, min_prod = min_prod, max_prod
```

如果当前数是负数，乘上负数后最大会变最小，最小会变最大，所以交换。

```python
max_prod = max(num, max_prod * num)
```

当前位置结尾的最大乘积有两种选择：

1. 从当前数字重新开始；
2. 接在之前最大乘积子数组后面。

```python
min_prod = min(num, min_prod * num)
```

同理，更新当前位置结尾的最小乘积。

```python
ans = max(ans, max_prod)
```

用当前位置的最大乘积更新全局答案。

```python
return ans
```

返回最大乘积。

#### 关键语法

- `nums[1:]`：从下标 1 开始的切片。
- `max_prod, min_prod = min_prod, max_prod`：Python 变量交换写法。
- 同时维护最大值和最小值，是本题关键。

#### 复杂度分析

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(1)`。

## 9. #416 分割等和子集

### 题目描述

给你一个只包含正整数的非空数组 `nums`。

请你判断是否可以把这个数组分成两个子集，使得两个子集的元素和相等。

### 示例

**示例 1：**

```text
输入: nums = [1,5,11,5]
输出: True
解释: 可以分成 [1,5,5] 和 [11]，两个子集和都是 11。
```

**示例 2：**

```text
输入: nums = [1,2,3,5]
输出: False
解释: 无法分成两个和相等的子集。
```

### Python 解法

```python
from typing import List

class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        total = sum(nums)

        if total % 2 == 1:
            return False

        target = total // 2
        dp = [False] * (target + 1)
        dp[0] = True

        for num in nums:
            for j in range(target, num - 1, -1):
                dp[j] = dp[j] or dp[j - num]

        return dp[target]
```

### 代码详细解析

#### 核心思路

如果数组能分成两个和相等的子集，那么总和必须是偶数。

问题就转化为：

```text
能否从 nums 中选出一些数，使它们的和等于 total // 2？
```

这是一个典型的 0/1 背包问题：

- 每个数字只能选一次；
- 背包容量是 `target`；
- 目标是判断是否能刚好装满。

定义：

```text
dp[j] = 是否可以从已处理的数字中选出一些，使和为 j
```

#### 逐行解析

```python
total = sum(nums)
```

计算数组总和。

```python
if total % 2 == 1:
    return False
```

如果总和是奇数，不可能分成两个相等整数和。

```python
target = total // 2
```

目标子集和。

```python
dp = [False] * (target + 1)
dp[0] = True
```

`dp[0] = True` 表示不选任何数，可以凑出和 0。

```python
for num in nums:
```

遍历每个数字。

```python
for j in range(target, num - 1, -1):
```

倒序遍历容量。  
这是 0/1 背包的关键，因为每个数字只能用一次。

```python
dp[j] = dp[j] or dp[j - num]
```

如果之前可以凑出 `j - num`，那么加上当前数字 `num` 后，就可以凑出 `j`。

```python
return dp[target]
```

返回是否可以凑出目标和。

#### 关键语法

- `sum(nums)`：计算列表总和。
- `% 2`：判断奇偶。
- `range(target, num - 1, -1)`：倒序遍历。
- `or`：逻辑或。

#### 为什么要倒序遍历

如果正序遍历，同一个 `num` 可能在一轮中被重复使用。  
倒序遍历可以保证每个数字只使用一次。

#### 复杂度分析

- 时间复杂度：`O(n * target)`。
- 空间复杂度：`O(target)`。

## 10. #32 最长有效括号

### 题目描述

给你一个只包含 `'('` 和 `')'` 的字符串 `s`，请你找出最长有效括号子串的长度。

有效括号子串必须是连续的，并且括号匹配正确。

### 示例

**示例 1：**

```text
输入: s = "(()"
输出: 2
解释: 最长有效括号子串是 "()"。
```

**示例 2：**

```text
输入: s = ")()())"
输出: 4
解释: 最长有效括号子串是 "()()"。
```

**示例 3：**

```text
输入: s = ""
输出: 0
```

### Python 解法：动态规划

```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        n = len(s)
        dp = [0] * n
        ans = 0

        for i in range(1, n):
            if s[i] == ")":
                if s[i - 1] == "(":
                    dp[i] = (dp[i - 2] if i >= 2 else 0) + 2
                else:
                    prev_index = i - dp[i - 1] - 1
                    if prev_index >= 0 and s[prev_index] == "(":
                        dp[i] = dp[i - 1] + 2
                        if prev_index - 1 >= 0:
                            dp[i] += dp[prev_index - 1]

                ans = max(ans, dp[i])

        return ans
```

### 代码详细解析

#### 核心思路

定义：

```text
dp[i] = 以 s[i] 结尾的最长有效括号子串长度
```

注意是“以 `s[i]` 结尾”，所以只有当 `s[i] == ')'` 时，才可能形成有效括号。

有两种情况：

### 情况 1：`s[i - 1] == '('`

形如：

```text
...()
```

那么：

```text
dp[i] = dp[i - 2] + 2
```

### 情况 2：`s[i - 1] == ')'`

形如：

```text
...))
```

如果前面已经有一段有效括号，长度是 `dp[i - 1]`，那么这段有效括号的前一个位置是：

```python
prev_index = i - dp[i - 1] - 1
```

如果这个位置是 `'('`，它就可以和当前 `')'` 匹配。

#### 逐行解析

```python
n = len(s)
dp = [0] * n
ans = 0
```

- `n` 是字符串长度；
- `dp[i]` 表示以 `i` 结尾的最长有效括号长度；
- `ans` 保存全局最大长度。

```python
for i in range(1, n):
```

从下标 1 开始，因为单个字符不可能构成有效括号。

```python
if s[i] == ")":
```

只有右括号才可能作为有效括号结尾。

```python
if s[i - 1] == "(":
```

如果前一个字符是左括号，形成 `"()"`。

```python
dp[i] = (dp[i - 2] if i >= 2 else 0) + 2
```

当前 `"()"` 前面可能还有一段有效括号。  
如果 `i >= 2`，就加上 `dp[i - 2]`。

```python
else:
    prev_index = i - dp[i - 1] - 1
```

如果前一个字符也是右括号，需要找能和当前右括号匹配的左括号位置。

```python
if prev_index >= 0 and s[prev_index] == "(":
```

如果这个位置存在，并且是左括号，说明可以匹配。

```python
dp[i] = dp[i - 1] + 2
```

先把中间那段有效括号和当前匹配的一对括号加起来。

```python
if prev_index - 1 >= 0:
    dp[i] += dp[prev_index - 1]
```

如果匹配左括号前面还有一段有效括号，也要接上。

```python
ans = max(ans, dp[i])
```

更新最大长度。

```python
return ans
```

返回答案。

#### 关键语法

- `dp[i - 2] if i >= 2 else 0`：三元表达式，用来避免下标越界。
- `prev_index = i - dp[i - 1] - 1`：本题最关键的下标计算。
- 动态规划关注的是“以当前位置结尾”的最优结果。

#### 复杂度分析

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(n)`。
