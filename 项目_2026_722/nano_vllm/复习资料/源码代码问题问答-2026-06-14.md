## 1. 问题：`@dataclass(slots=True)` 详细解释 dataclass 的用法以及后面的括号里有哪些常用的参数

### 复习版答案

`@dataclass` 是 Python 标准库 `dataclasses` 提供的装饰器，适合定义“数据容器类 / 参数类 / 配置类”。它会根据类中的字段自动生成常用方法，例如：

- `__init__`：自动接收字段参数并赋值；
- `__repr__`：打印对象时显示字段和值；
- `__eq__`：按字段内容比较两个对象是否相等。

例如：

```python
from dataclasses import dataclass

@dataclass
class SamplingParams:
    temperature: float = 1.0
    max_tokens: int = 64
    ignore_eos: bool = False
```

等价于手写一个保存三个属性的类。实例化后：

```python
params = SamplingParams(temperature=0.6, max_tokens=256)
```

对象中保存：

```text
temperature = 0.6
max_tokens = 256
ignore_eos = False
```

`slots=True` 表示启用 `__slots__`，对象只能拥有声明过的字段，不能随便添加新属性，例如不能再动态加 `params.top_p = 0.9`。好处是节省内存、防止误写字段，适合推理引擎里大量创建的小型参数对象。

`dataclass(...)` 常用参数：

```text
init=True       自动生成 __init__
repr=True       自动生成友好的打印形式
eq=True         自动生成内容相等比较
order=False     是否支持大小排序
frozen=False    是否让对象创建后不可修改
slots=False     是否启用固定字段、节省内存
kw_only=False   是否强制使用关键字参数创建对象
unsafe_hash=False 是否强制生成 hash，一般少用
```

在 nano-vLLM 里，`@dataclass(slots=True)` 的核心作用是：快速定义一个轻量参数容器，例如 `SamplingParams`，用来保存采样配置。

## 2. 问题：`repr` 是什么作用

### 复习版答案

`repr` 来自 `representation`，表示“对象的调试表示形式”。Python 中对应特殊方法：

```python
__repr__()
```

它决定对象在打印或调试时显示成什么样子。

例如字符串：

```python
x = "hello"
print(x)       # hello
print(repr(x)) # 'hello'
```

`print(x)` 更偏向普通显示，`repr(x)` 更偏向调试显示，会保留引号、换行符等原始信息。

在 `dataclass` 中，默认 `repr=True`，所以对象打印时能直接显示字段：

```python
params = SamplingParams(temperature=0.6, max_tokens=256)
print(params)
```

输出类似：

```text
SamplingParams(temperature=0.6, max_tokens=256, ignore_eos=False)
```

如果没有友好的 `repr`，普通类打印可能只是：

```text
<__main__.SamplingParams object at 0x...>
```

不利于调试。

之前代码中的：

```python
print(f"Prompt: {prompt!r}")
```

里面的 `!r` 就是调用 `repr(prompt)`，用于显示更适合调试的字符串形式。

一句话：`repr` 的作用是让对象以“程序员能看清内部状态”的形式显示出来。

## 3. 问题：`__post_init__` 详解

### 复习版答案

`__post_init__` 是 `dataclass` 的特殊方法，表示：

```text
dataclass 自动生成的 __init__ 执行完之后，再自动执行的补充初始化函数。
```

典型流程：

```text
1. 创建对象
2. 自动给字段赋值
3. 自动调用 __post_init__()
4. 在其中做检查、转换或派生字段计算
```

例如：

```python
@dataclass
class SamplingParams:
    temperature: float = 1.0

    def __post_init__(self):
        assert self.temperature > 1e-10
```

创建对象时：

```python
params = SamplingParams(temperature=0.6)
```

会先赋值：

```text
self.temperature = 0.6
```

然后自动执行：

```python
self.__post_init__()
```

常见用途：

```text
1. 参数合法性检查
2. 根据已有字段计算新字段
3. 路径展开、类型转换、归一化处理
```

例如 nano-vLLM 中：

```python
def __post_init__(self):
    assert self.temperature > 1e-10, "greedy sampling is not permitted"
```

含义是：`SamplingParams` 对象创建后，立刻检查 `temperature` 是否太小。如果接近 0，就认为用户想做 greedy sampling，而当前实现不允许。

注意：没有 `@dataclass` 时，普通类里的 `__post_init__` 不会自动执行。

一句话：`__post_init__` 是 dataclass 初始化完成后的“补充检查/补充处理入口”。

## 4. 问题：`assert` 详解

### 复习版答案

`assert` 是 Python 的断言语句，用来检查程序中的某个条件是否成立。

基本语法：

```python
assert 条件
assert 条件, "错误提示信息"
```

执行逻辑：

```text
条件为 True：程序继续运行
条件为 False：抛出 AssertionError
```

例如：

```python
x = -1
assert x > 0, "x must be positive"
```

会报错：

```text
AssertionError: x must be positive
```

它大致等价于：

```python
if not x > 0:
    raise AssertionError("x must be positive")
```

在 nano-vLLM 中：

```python
assert self.temperature > 1e-10, "greedy sampling is not permitted"
```

意思是：

```text
temperature 必须大于 1e-10；
如果小于等于这个值，就报 AssertionError；
错误信息是 greedy sampling is not permitted。
```

`1e-10` 是科学计数法，等于：

```text
0.0000000001
```

所以这句本质上是在禁止 `temperature` 为 0 或非常接近 0。原因是 temperature 接近 0 时，采样会退化成 greedy sampling，即每一步都选择概率最高的 token，而该简化实现不支持这种模式。

注意：`assert` 更适合开发阶段验证程序假设。正式参数校验更稳妥的写法通常是：

```python
if self.temperature <= 1e-10:
    raise ValueError("greedy sampling is not permitted")
```

因为 Python 使用 `python -O` 优化模式运行时，`assert` 可能会被忽略。

一句话：`assert` 是用来验证“这里理论上应该成立”的条件；条件不成立就立即报错，帮助暴露程序或参数问题。
